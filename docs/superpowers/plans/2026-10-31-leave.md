# Leave (spec 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Leave in AMG Shift Central: allowances in use, costing from the rota, the pro-rata rules, bank holidays, requests and approvals, balances with statements, the year planner and leave report, email notifications, and the GP leave feed the GP rota app reads instead of FindMyShift.

**Architecture:** A new `leave` Django app. A `Booking` holds a request or a manager's booking; on approval one `BookingDay` per day carries its cost (seconds) and covers that day's grid entries (`Entry.covered_by`), which leave the grid, hours and notify but stay in the table. Balances are never stored: `balances.statement()` recomputes pro-rated allowance + adjustments − approved costs and lists the lines. Screens are server-rendered through `modal.js`; the island only draws a leave tile and treats the cell as read-only. Shift Central serves `/api/v1/leave`; the rota app's FindMyShift reader is replaced by a Shift Central reader.

**Tech Stack:** Django 5.2 / Python 3.13 / SQLite (WAL); Unfold admin; Vite 6 + Preact 10 + TypeScript 5 (`frontend/`, bundle committed to `static/dist/`); pytest; vitest; Playwright for one e2e test. Rota app: Django 5.2, same toolchain, no build step.

**Spec:** `docs/superpowers/specs/2026-10-31-leave-design.md` (binding). Also read the grid spec `docs/superpowers/specs/2026-10-29-rota-grid-design.md` section 4 (services) and the Foundation spec's access rules before Tasks 4 to 9.

## Global Constraints

- Every write goes through `leave/services/`; views never touch models. Every service audits through `people.services.audit.record_as(actor, "leave.booking" | "leave.adjustment" | "people.allowance", person.pk, {field: (before, after)}, note)`.
- Secrets from the environment only (`LEAVE_API_TOKENS`, `SHIFT_CENTRAL_TOKEN`). No key, token or password in any repo file, test fixture or log line.
- Log lines, `Outbox.error`, `SyncRun.message` and the GP leave feed body never carry a description, a note, a reason or a name. The feed carries emails only because they are the match key.
- Costs and balances are **integer seconds** in Python and the database; screens show `hours.fmt()` ("7 h 30 min", "2 h 37½ min", "−1 h 30 min"). Allowance boxes stay Decimal hours to two places.
- Dates and "today" are Europe/London: `timezone.localdate()`.
- CSP forbids inline scripts and handlers: no `onclick`, no `<script>` in templates; dialogs use `data-dialog`, `data-dialog-form`, `data-submit-on-change`, `data-dialog-refresh`.

Every commit ends with the two trailer lines given in the session (Co-Authored-By and Claude-Session). No model identifier anywhere in a repo file.

```python
from django.conf import settings
from django.db import models
from django.db.models import F, Q


class Booking(models.Model):
    class Part(models.TextChoices):
        WHOLE = "whole", "Whole day"
        AM = "am", "Morning"
        PM = "pm", "Afternoon"
        TIMES = "times", "Times"

    class Status(models.TextChoices):
        PENDING = "pending", "Waiting for approval"
        APPROVED = "approved", "Approved"
        DECLINED = "declined", "Declined"
        CANCEL_REQUESTED = "cancel_requested", "Cancellation requested"
        CANCELLED = "cancelled", "Cancelled"

    ACTIVE = (Status.APPROVED, Status.CANCEL_REQUESTED)   # statuses whose days cost and cover
    LIVE = (Status.PENDING, Status.APPROVED, Status.CANCEL_REQUESTED)   # statuses that block an overlap

    person = models.ForeignKey("people.Person", on_delete=models.PROTECT, related_name="bookings")
    type = models.ForeignKey("leave.LeaveType", on_delete=models.PROTECT, related_name="bookings")
    description = models.CharField(max_length=80, blank=True, default="")
    first_day = models.DateField()
    last_day = models.DateField()
    part = models.CharField(max_length=5, choices=Part.choices, default=Part.WHOLE)
    start = models.TimeField(null=True, blank=True)
    finish = models.TimeField(null=True, blank=True)
    paid = models.BooleanField(null=True, blank=True)
    status = models.CharField(max_length=16, choices=Status.choices, default=Status.PENDING, db_index=True)
    requested_by = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, blank=True, on_delete=models.SET_NULL, related_name="+")
    requested_at = models.DateTimeField(auto_now_add=True)
    decided_by = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, blank=True, on_delete=models.SET_NULL, related_name="+")
    decided_at = models.DateTimeField(null=True, blank=True)
    cancel_requested_at = models.DateTimeField(null=True, blank=True)
    cancel_decided_by = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, blank=True, on_delete=models.SET_NULL, related_name="+")
    cancel_decided_at = models.DateTimeField(null=True, blank=True)
    staff_note = models.CharField(max_length=300, blank=True, default="")
    manager_note = models.CharField(max_length=300, blank=True, default="")
    reminded_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        ordering = ["-first_day", "-pk"]
        indexes = [models.Index(fields=["person", "first_day"])]
        constraints = [
            models.CheckConstraint(condition=Q(first_day__lte=F("last_day")), name="booking_days_in_order"),
            models.CheckConstraint(condition=Q(part="whole") | Q(first_day=F("last_day")), name="part_day_is_one_day"),
            models.CheckConstraint(
                condition=(Q(part="times", start__isnull=False, finish__isnull=False, start__lt=F("finish"))
                           | (~Q(part="times") & Q(start__isnull=True, finish__isnull=True))),
                name="times_have_start_before_finish"),
        ]

    @property
    def label(self):
        return self.description or self.type.name

    @property
    def is_active(self):
        return self.status in self.ACTIVE

    def days(self):
        from datetime import timedelta
        d = self.first_day
        while d <= self.last_day:
            yield d
            d += timedelta(days=1)

    def __str__(self):
        return f"{self.person_id} {self.type_id} {self.first_day}..{self.last_day} {self.status}"
```

```python
    class Meta:
        ordering = ["first_day"]
```

`leave/services/prorata.py`:

```python
"""LEAVE-10 to 13. Each Allowance row of the year is a period from its
from_day to the day before the next row, cut to the person's employment
and the year. weeks = days / 7 rounded up (a part week is whole, on both
sides of a change: the week of the change counts twice, the practice's
deliberate choice). The shares are summed, rounded ONCE to the nearest
half hour (ties up), then capped at the largest full-year figure among the
rows, which is also what makes a 53-week whole year exactly the full
allowance (LEAVE-13)."""

from dataclasses import dataclass
from datetime import timedelta
from decimal import ROUND_HALF_UP, Decimal

from leave.services import hours, years
from people.models import Allowance

FIELD = {"annual": "annual_hours", "bank_holiday": "bank_holiday_hours"}


@dataclass(frozen=True)
class Line:
    from_day: object
    to_day: object
    days: int
    weeks: int
    full_hours: Decimal
    share_hours: Decimal


@dataclass(frozen=True)
class ProRata:
    seconds: int
    lines: list
    capped: bool
    missing: bool = False


def rows_for(person, year):
    return list(Allowance.objects.filter(person=person, leave_year=year).order_by("from_day"))


def row_in_force(person, day):
    year = years.year_of(person, day)
    return Allowance.objects.filter(person=person, leave_year=year, from_day__lte=day).order_by("-from_day").first()


def allowance(person, year, account):
    rows = rows_for(person, year)
    if not rows:
        return ProRata(0, [], False, missing=True)
    field = FIELD[account]
    year_end = years.year_end(year)
    total, lines = Decimal(0), []
    for i, row in enumerate(rows):
        start = max(row.from_day, person.start_date, year)
        end = rows[i + 1].from_day - timedelta(days=1) if i + 1 < len(rows) else year_end
        if person.end_date:
            end = min(end, person.end_date)
        if end < start:
            continue
        days = (end - start).days + 1
        weeks = -(-days // 7)
        full = getattr(row, field)
        share = full / Decimal(52) * weeks
        total += share
        lines.append(Line(start, end, days, weeks, full, share))
    rounded = (total * 2).quantize(Decimal(1), rounding=ROUND_HALF_UP) / 2
    cap = max(getattr(r, field) for r in rows)
    capped = rounded > cap
    return ProRata(hours.from_hours(min(rounded, cap)), lines, capped)
```

```python
def add_hours_change(actor, person, from_day, weekly_hours, days_per_week, annual_hours, bank_holiday_hours, note):
    """A dated change of contract (PAT-06, LEAVE-12): a second Allowance row
    for the year from `from_day`, carrying the new full-year figures and the
    new weekly hours and days. The year's first row must exist; the first
    day itself is set_allowance's. When the day has arrived the hours go on
    the person now; otherwise apply_due_hours_changes() copies them on the day."""
    from leave.services import years
    if not note or not note.strip():
        raise ValueError("A reason is needed for an hours change")
    year = years.year_of(person, from_day)
    if from_day == year:
        raise ValueError("Set the year's allowance on the Pay & time off tab; a change starts after the year's first day")

    today = today or timezone.localdate()

            .exclude(from_day=models.F("leave_year")).select_related("person").order_by("person_id", "-from_day"))
```

```python
"""What a day of leave costs (LEAVE-05 to 09, 16, 23) and which account it
draws on (LEAVE-17, 18). A GP's day is their sessions at 4 h 10 min; a GP has
no placeholder because their sessions come from the rota app."""

from collections import Counter
from dataclasses import dataclass
from datetime import datetime, timedelta

from django.db.models import Q

from leave.models import BankHoliday, Booking, BookingDay
from leave.services import hours, prorata
from shifts.models import Entry, GpSession
from shifts.services.window import monday

ACTIVE = Booking.ACTIVE


@dataclass(frozen=True)
class DayCost:
    seconds: int
    source: str
    account: str
    placeholder: bool = False
    hours_known: bool = True


def _shifts(person, day, include=None):
    rows = Entry.objects.filter(person=person, day=day, kind=Entry.Kind.SHIFT, overtime="")
    cover = Q(covered_by__isnull=True)
    if include is not None:
        cover |= Q(covered_by=include)
    return rows.filter(cover)


def rota_seconds(person, day, include=None):
    worked = sum((e.hours for e in _shifts(person, day, include)), timedelta(0))
    sessions = GpSession.objects.filter(person=person, day=day).count()
    return int(worked.total_seconds()) + sessions * hours.GP_SESSION


def is_placeholder(person, day):
    """LEAVE-06: the rota "has not been set" for a day when the person's
    Monday-to-Sunday week holds no entry and no session. A GP never has one."""
    if person.is_gp:
        return False
    first = monday(day)
    week = (first, first + timedelta(days=6))
    return not (Entry.objects.filter(person=person, day__range=week).exists()
                or GpSession.objects.filter(person=person, day__range=week).exists())


def placeholder_seconds(person, day):
    """Weekly hours ÷ days per week from the Allowance row in force that day
    when it carries hours, else the person's figures; (0, False) when
    neither is set, so the caller can say so."""
    row = prorata.row_in_force(person, day)
    weekly, days = (row.weekly_hours, row.days_per_week) if row and row.weekly_hours is not None else (person.weekly_hours, person.days_per_week)
    if weekly is None or not days:
        return 0, False
    return hours.from_hours(weekly) // days, True


def account_for(leave_type, day):
    if leave_type.draws_from == "annual" and BankHoliday.objects.filter(day=day).exists():
        return "bank_holiday"
    return leave_type.draws_from


def cost(person, leave_type, day, part, start=None, finish=None, include=None):
    account = account_for(leave_type, day)
    if part == "times":
        anchor = datetime(2000, 1, 1)
        seconds = int((datetime.combine(anchor, finish) - datetime.combine(anchor, start)).total_seconds())
        return DayCost(seconds, "times", account)
    whole = rota_seconds(person, day, include)
    placeholder, known = False, True
    if whole == 0 and is_placeholder(person, day):
        whole, known = placeholder_seconds(person, day)
        placeholder = True
    if part in ("am", "pm"):
        return DayCost(whole // 2, "half", account, placeholder, known)
    if placeholder:
        return DayCost(whole, "placeholder", account, True, known)
    return DayCost(whole, "rota" if whole else "none", account)


def suggestion(person, day):
    """LEAVE-16: the most common rota cost on that weekday over the four
    weeks before the holiday; ties go to the larger figure; 0 when none."""
    figures = Counter(rota_seconds(person, day - timedelta(weeks=w)) for w in range(1, 5))
    best = max(figures.items(), key=lambda kv: (kv[1], kv[0]))
    return best[0]


def active_day(person, day):
    return (BookingDay.objects.filter(booking__person=person, day=day, booking__status__in=ACTIVE)
            .select_related("booking__type").first())
```

```python
"""Balances are never stored (REP-10). A statement is recomputed from the
pro-rated allowances, the adjustments and the approved bookings, and lists
the lines that make it up."""

from dataclasses import dataclass, field
from datetime import timedelta
from decimal import Decimal

from django.db.models import Sum
from django.utils import timezone

from leave.models import Adjustment, Booking, BookingDay
from leave.services import costing, hours, prorata, years
from shifts.models import Entry

ACCOUNTS = ("annual", "bank_holiday", "toil", "none")


@dataclass
class Statement:
    person: object
    year: object
    prorata: dict
    annual_allowance: int = 0
    bank_holiday_allowance: int = 0
    adjustments: dict = field(default_factory=dict)
    taken: dict = field(default_factory=dict)
    pending: dict = field(default_factory=dict)
    bank_holiday_balance: int = 0
    annual_remaining: int = 0
    annual_available: int = 0
    toil_earned: int = 0
    toil_remaining: int = 0
    toil_available: int = 0
    missing: bool = False
    lines: list = field(default_factory=list)


def _zero():
    return {a: 0 for a in ACCOUNTS}


def toil_earned(person, today=None):
    today = today or timezone.localdate()
    worked = sum((e.hours for e in Entry.objects.filter(person=person, kind=Entry.Kind.SHIFT, overtime="toil", day__lte=today,
                                                        covered_by__isnull=True)), timedelta(0))
    return int(worked.total_seconds())


def _pending_costs(person, year):
    out = _zero()
    end = years.year_end(year)
    for b in Booking.objects.filter(person=person, status=Booking.Status.PENDING, first_day__lte=end, last_day__gte=year).select_related("type"):
        for day in b.days():
            if year <= day <= end:
                c = costing.cost(person, b.type, day, b.part, b.start, b.finish)
                out[c.account] += c.seconds
    return out


def statement(person, year):
    pr = {a: prorata.allowance(person, year, a) for a in ("annual", "bank_holiday")}
    s = Statement(person, year, pr, missing=pr["annual"].missing)
    s.annual_allowance, s.bank_holiday_allowance = pr["annual"].seconds, pr["bank_holiday"].seconds
    s.adjustments = _zero()
    for row in Adjustment.objects.filter(person=person, leave_year=year):
        s.adjustments[row.account] += row.seconds
    s.taken = _zero()
    end = years.year_end(year)
    days = (BookingDay.objects.filter(booking__person=person, booking__status__in=Booking.ACTIVE, day__range=(year, end))
            .values("account").annotate(total=Sum("cost_seconds")))
    for row in days:
        s.taken[row["account"]] += row["total"] or 0
    s.pending = _pending_costs(person, year)
    s.bank_holiday_balance = s.bank_holiday_allowance + s.adjustments["bank_holiday"] - s.taken["bank_holiday"]
    s.annual_remaining = s.annual_allowance + s.adjustments["annual"] - s.taken["annual"] + s.bank_holiday_balance
    s.annual_available = s.annual_remaining - s.pending["annual"] - s.pending["bank_holiday"]
    s.toil_earned = toil_earned(person)
    s.toil_remaining = s.toil_earned + s.adjustments["toil"] - s.taken["toil"]
    s.toil_available = s.toil_remaining - s.pending["toil"]
    s.lines = _lines(s)
    return s


def _lines(s):
    out = []
    for account, label in (("annual", "Annual leave allowance"), ("bank_holiday", "Bank holiday allowance")):
        pr = s.prorata[account]
        if pr.missing:
            out.append(("allowance", f"{label}: not set", 0))
            continue
        for ln in pr.lines:
            out.append(("allowance", f"{label} {ln.from_day:%-d %b}–{ln.to_day:%-d %b}: {ln.weeks} weeks of 52 at {ln.full_hours} h", hours.from_hours(ln.share_hours.quantize(Decimal("0.01")))))
        if len(pr.lines) != 1 or pr.capped or pr.seconds != hours.from_hours(pr.lines[0].share_hours.quantize(Decimal("0.01"))):
            out.append(("allowance", f"{label} rounded to the half hour{' and capped at the full-year figure' if pr.capped else ''}", pr.seconds))
    for row in Adjustment.objects.filter(person=s.person, leave_year=s.year).order_by("at"):
        out.append(("adjustment", f"{row.reason} ({row.account.replace('_', ' ')})", row.seconds))
    for bd in (BookingDay.objects.filter(booking__person=s.person, booking__status__in=Booking.ACTIVE, day__range=(s.year, years.year_end(s.year)))
               .select_related("booking__type").order_by("day")):
        out.append(("booking", f"{bd.day:%a %-d %b}: {bd.booking.label} ({bd.account.replace('_', ' ')}, {bd.get_source_display().lower()})", -bd.cost_seconds))
    out.append(("bank_holiday_balance", "Bank holiday allowance less bank holidays taken (moves into annual leave)", s.bank_holiday_balance))
    out.append(("remaining", "Annual leave remaining, bank holidays included", s.annual_remaining))
    out.append(("toil", "TOIL earned (overtime marked TOIL, to today)", s.toil_earned))
    out.append(("toil_remaining", "TOIL remaining", s.toil_remaining))
    return out


def available(person, year, account):
    if account == "none":
        return None
    s = statement(person, year)
    return s.toil_available if account == "toil" else s.annual_available
```

```python
"""The booking lifecycle (spec section 4). Every function audits under
leave.booking against the person; every write is one transaction; emails
go after the commit through leave.services.notify, which never raises."""

from datetime import datetime, time

from django.core.exceptions import PermissionDenied
from django.db import transaction
from django.utils import timezone

from leave.models import Booking, BookingDay
from leave.services import balances, blackouts, costing, notify, years
from leave.services.common import LeaveError, check_manager, describe
from people.services import access, audit
from shifts.models import Entry
from shifts.services import render
from shifts.services.entries import _touch

ACCOUNT_LABEL = {"annual": "annual leave", "bank_holiday": "bank holiday allowance", "toil": "TOIL"}


# --- who may --------------------------------------------------------------

def may_request(user, person):
    return access.is_self(user, person)


def may_book(user, person):
    return access.can_manage(user, person) or (access.is_self(user, person) and person.own_leave_without_approval)


def may_decide(user, booking):
    return access.can_manage(user, booking.person)


def may_view_detail(user, booking):
    return access.is_self(user, booking.person) or access.can_manage(user, booking.person)


# --- checks ---------------------------------------------------------------

def _check_dates(person, first, last, part, start, finish):
    if first > last:
        raise LeaveError("dates", "The last day is before the first")
    if part != "whole" and first != last:
        raise LeaveError("dates", "A half day or times is one day")
    if part == "times" and (start is None or finish is None or start >= finish):
        raise LeaveError("dates", "Give a start before a finish")
    if part != "times" and (start or finish):
        raise LeaveError("dates", "Times are for a timed booking only")
    allowed = years.years_for(person)
    if years.year_of(person, first) not in allowed or years.year_of(person, last) not in allowed:
        raise LeaveError("dates", "Leave can be booked in this leave year and the next")


def _check_overlap(person, first, last, exclude=None):
    rows = Booking.objects.filter(person=person, status__in=Booking.LIVE, first_day__lte=last, last_day__gte=first)
    if exclude is not None:
        rows = rows.exclude(pk=exclude.pk)
    clash = rows.first()
    if clash is not None:
        raise LeaveError("overlap", f"{clash.label} is already booked for {clash.first_day:%-d %b}")


def preview(person, leave_type, first, last, part, start=None, finish=None):
    probe = Booking(person=person, type=leave_type, first_day=first, last_day=last, part=part, start=start, finish=finish)
    return [costing.cost(person, leave_type, d, part, start, finish) for d in probe.days()]


def _total(costs):
    out = {}
    for c in costs:
        out[c.account] = out.get(c.account, 0) + c.seconds
    return out


def _check_balance(person, first, costs):
    year = years.year_of(person, first)
    for account, seconds in _total(costs).items():
        if account == "none" or seconds == 0:
            continue
        available = balances.available(person, year, account)
        if available is not None and seconds > available:
            from leave.services import hours
            raise LeaveError("balance", f"This would take {hours.fmt(seconds)} of {ACCOUNT_LABEL[account]} and {hours.fmt(max(available, 0))} is available")


def suggestion_for(person, day):
    return costing.suggestion(person, day)


# --- request and book -----------------------------------------------------

def _new(user, person, leave_type, first, last, part, start, finish, description, paid, note, status):
    if leave_type.archived:
        raise LeaveError("type", "That leave type is no longer in use")
    if leave_type.paid_choice:
        paid = leave_type.default_paid if paid is None else bool(paid)
    else:
        paid = None if leave_type.name != "Unpaid leave" else False
    return Booking(person=person, type=leave_type, first_day=first, last_day=last, part=part, start=start, finish=finish,
                   description=(description or "").strip()[:80], paid=paid, status=status, requested_by=user,
                   staff_note=(note or "")[:300] if status == Booking.Status.PENDING else "",
                   manager_note=(note or "")[:300] if status != Booking.Status.PENDING else "")


def request(user, person, leave_type, first, last, part, start=None, finish=None, description="", paid=None, note="", base_url=""):
    if not may_request(user, person):
        raise PermissionDenied("you can only request your own leave")
    if not leave_type.requestable:
        raise LeaveError("type", f"{leave_type.name} is recorded by a manager, not requested")
    _check_dates(person, first, last, part, start, finish)
    _check_overlap(person, first, last)
    for day in Booking(first_day=first, last_day=last).days():
        if blackouts.blocks(person, day):
            raise LeaveError("blackout", f"Leave cannot be requested for {day:%a %-d %b}")
    costs = preview(person, leave_type, first, last, part, start, finish)
    _check_balance(person, first, costs)
    booking = _new(user, person, leave_type, first, last, part, start, finish, description, paid, note, Booking.Status.PENDING)
    with transaction.atomic():
        booking.save()
        audit.record_as(user, "leave.booking", person.pk, {"booking": ("", describe(booking, sum(c.seconds for c in costs)))}, note="requested")
    notify.request_made(booking, base_url)
    return booking


def book(user, person, leave_type, first, last, part, start=None, finish=None, description="", paid=None, note="", costs=None, base_url=""):
    """A manager's booking, approved as it is made. `costs` is {day: seconds}
    typed on the Advanced tab; each becomes an override."""
    if not may_book(user, person):
        raise PermissionDenied("you don't manage this person")
    _check_dates(person, first, last, part, start, finish)
    _check_overlap(person, first, last)
    booking = _new(user, person, leave_type, first, last, part, start, finish, description, paid, note, Booking.Status.APPROVED)
    booking.decided_by, booking.decided_at = user, timezone.now()
    with transaction.atomic():
        booking.save()
        days = _apply(booking)
        for bd in days:
            typed = (costs or {}).get(bd.day)
            if typed is not None:          # a typed figure is always an override, so a bank holiday day reads "bank holiday" even at the rota's cost
                bd.cost_seconds, bd.source, bd.placeholder = int(typed), BookingDay.Source.OVERRIDE, False
                bd.override_by, bd.override_note = user, (note or "set when booked")[:300]
                bd.save()
        audit.record_as(user, "leave.booking", person.pk, {"booking": ("", describe(booking))}, note="booked by a manager")
    _after_apply(booking, days, base_url)
    return booking


def approve(user, booking, note="", base_url=""):
    if not may_decide(user, booking):
        raise PermissionDenied("you don't manage this person")
    if booking.status != Booking.Status.PENDING:
        raise LeaveError("status", "This request has already been decided")
    _check_overlap(booking.person, booking.first_day, booking.last_day, exclude=booking)
    before = describe(booking)
    with transaction.atomic():
        booking.status, booking.decided_by, booking.decided_at, booking.manager_note = Booking.Status.APPROVED, user, timezone.now(), (note or "")[:300]
        booking.save()
        days = _apply(booking)
        audit.record_as(user, "leave.booking", booking.person_id, {"booking": (before, describe(booking))}, note="approved")
    notify.decided(booking, base_url)
    _after_apply(booking, days, base_url, decided_mail_sent=True)


def decline(user, booking, note="", base_url=""):
    if not may_decide(user, booking):
        raise PermissionDenied("you don't manage this person")
    if booking.status != Booking.Status.PENDING:
        raise LeaveError("status", "This request has already been decided")
    before = describe(booking)
    with transaction.atomic():
        booking.status, booking.decided_by, booking.decided_at, booking.manager_note = Booking.Status.DECLINED, user, timezone.now(), (note or "")[:300]
        booking.save()
        audit.record_as(user, "leave.booking", booking.person_id, {"booking": (before, describe(booking))}, note="declined")
    notify.decided(booking, base_url)


# --- apply and undo -------------------------------------------------------

def _shorten(booking, day):
    """The one uncovered shift whose span contains the leave; returns the
    entry and its original times, or (None, None, None)."""
    for e in Entry.objects.filter(person=booking.person, day=day, kind=Entry.Kind.SHIFT, covered_by__isnull=True).order_by("position"):
        if e.start <= booking.start and e.finish >= booking.finish:
            original = (e.start, e.finish)
            if booking.start == e.start:
                e.start = booking.finish
            elif booking.finish == e.finish:
                e.finish = booking.start
            else:
                e.finish = booking.start
            if e.start >= e.finish:
                # the leave is the whole shift: keep the row, cover it instead
                e.start, e.finish = original
                return e, None, None
            e.save(update_fields=["start", "finish", "updated_at"])
            return e, original[0], original[1]
    return None, None, None


def _apply(booking):
    """Cost each day, write its BookingDay, cover or shorten the entries,
    record a DayChange where the day's text changes. Inside the caller's
    transaction."""
    days = []
    for day in booking.days():
        before = render.day_text(booking.person, day)
        c = costing.cost(booking.person, booking.type, day, booking.part, booking.start, booking.finish)
        bd = BookingDay.objects.create(booking=booking, day=day, cost_seconds=c.seconds, source=c.source, account=c.account, placeholder=c.placeholder)
        if booking.part == Booking.Part.TIMES:
            entry, s, f = _shorten(booking, day)
            if entry is not None and s is None:
                Entry.objects.filter(pk=entry.pk).update(covered_by=bd)
            elif entry is not None:
                bd.shortened_entry, bd.original_start, bd.original_finish = entry, s, f
                bd.save(update_fields=["shortened_entry", "original_start", "original_finish"])
        else:
            Entry.objects.filter(person=booking.person, day=day, covered_by__isnull=True).update(covered_by=bd)
        if render.day_text(booking.person, day) != before:
            _touch(booking.person, day, before=before)
        days.append(bd)
    return days


def _undo(booking):
    for bd in BookingDay.objects.filter(booking=booking).select_related("shortened_entry"):
        before = render.day_text(booking.person, bd.day)
        Entry.objects.filter(covered_by=bd).update(covered_by=None)
        e = bd.shortened_entry
        if e is not None and bd.original_start is not None:
            e.start, e.finish = bd.original_start, bd.original_finish
            e.save(update_fields=["start", "finish", "updated_at"])
        bd.delete()
        if render.day_text(booking.person, bd.day) != before:
            _touch(booking.person, bd.day, before=before)


def _after_apply(booking, days, base_url, decided_mail_sent=False):
    flagged = [bd for bd in days if bd.placeholder]
    if flagged:
        notify.cost_to_check(booking.person, flagged, base_url)

def request_cancel(user, booking, note="", base_url=""):

        raise PermissionDenied("you can only cancel your own leave")
    if booking.status != Booking.Status.APPROVED:

EDITABLE = ("type", "first", "last", "part", "start", "finish", "description", "paid")


def edit(user, booking, base_url="", **fields):
    if not may_decide(user, booking):
        raise PermissionDenied("you don't manage this person")
    if booking.status not in (Booking.Status.APPROVED, Booking.Status.PENDING):
        raise LeaveError("status", "Only approved or pending leave can be edited")
    unknown = set(fields) - set(EDITABLE)
    if unknown:
        raise ValueError(f"not editable: {sorted(unknown)}")
    first = fields.get("first", booking.first_day)
    last = fields.get("last", booking.last_day)
    part = fields.get("part", booking.part)
    start = fields.get("start", booking.start) if part == "times" else None
    finish = fields.get("finish", booking.finish) if part == "times" else None
    _check_dates(booking.person, first, last, part, start, finish)
    _check_overlap(booking.person, first, last, exclude=booking)
    before = describe(booking)
    with transaction.atomic():
        was_active = booking.is_active
        if was_active:
            _undo(booking)
        booking.first_day, booking.last_day, booking.part, booking.start, booking.finish = first, last, part, start, finish
        if "type" in fields:
            booking.type = fields["type"]
        if "description" in fields:
            booking.description = (fields["description"] or "").strip()[:80]
        if "paid" in fields and booking.type.paid_choice:
            booking.paid = bool(fields["paid"])
        booking.save()
        days = _apply(booking) if was_active else []
        audit.record_as(user, "leave.booking", booking.person_id, {"booking": (before, describe(booking))}, note="edited by a manager")
    _after_apply(booking, days, base_url)


def override_day(user, booking_day, seconds, note):
    if not may_decide(user, booking_day.booking):
        raise PermissionDenied("you don't manage this person")
    if not (note or "").strip():
        raise ValueError("A reason is needed to override a day's cost")
    before = booking_day.cost_seconds
    with transaction.atomic():
        booking_day.cost_seconds, booking_day.source, booking_day.placeholder = int(seconds), BookingDay.Source.OVERRIDE, False
        booking_day.override_by, booking_day.override_note = user, note.strip()[:300]
        booking_day.save()
        from leave.services import hours
        audit.record_as(user, "leave.booking", booking_day.booking.person_id,
                        {f"cost {booking_day.day.isoformat()}": (hours.fmt(before), hours.fmt(booking_day.cost_seconds))}, note=note.strip()[:300])


def recost(booking_day):
    """Re-cost a whole day from the rota; half-day, timed and overridden days
    keep their cost. Covers the day's entries either way. Returns whether
    the figure changed."""
    booking = booking_day.booking
    if booking.part == Booking.Part.TIMES or booking_day.source == BookingDay.Source.OVERRIDE:
        return False
    Entry.objects.filter(person=booking.person, day=booking_day.day, covered_by__isnull=True).update(covered_by=booking_day)
    if booking.part != Booking.Part.WHOLE:
        return False
    c = costing.cost(booking.person, booking.type, booking_day.day, "whole", include=booking_day)
    changed = c.seconds != booking_day.cost_seconds or booking_day.placeholder
    booking_day.cost_seconds, booking_day.source, booking_day.placeholder = c.seconds, c.source, c.placeholder
    booking_day.save(update_fields=["cost_seconds", "source", "placeholder"])
    return changed


def after_rota_write(person, day, base_url=""):
    """Called by entries._write after writing a day that has an active
    BookingDay. Covers the new entries, re-costs, flags managers when the
    cost changed, and returns the pks of the entries still visible."""
    bd = costing.active_day(person, day)
    if bd is None:
        return list(Entry.objects.filter(person=person, day=day).values_list("pk", flat=True))
    if recost(bd):
        notify.cost_to_check(person, [bd], base_url)
    return list(Entry.objects.filter(person=person, day=day, covered_by__isnull=True).values_list("pk", flat=True))
```

```python
def blocks(person, day):
    rows = Blackout.objects.filter(first_day__lte=day, last_day__gte=day)
    if person.team_id:
        rows = rows.filter(Q(teams__isnull=True) | Q(teams=person.team_id))
    else:
        rows = rows.filter(teams__isnull=True)
    return rows.exists()


def _manager(user):
    if not access.is_manager(user):
        raise PermissionDenied("managers only")


def add(user, first, last, teams, note=""):
    _manager(user)
    if first > last:
        raise ValueError("The last day is before the first")
    row = Blackout.objects.create(first_day=first, last_day=last, note=(note or "")[:120])
    row.teams.set(teams)
    audit.record(user, row, {"blackout": ("", f"{first}..{last} {note}".strip())})
    return row


def update(user, row, first, last, teams, note=""):
    _manager(user)
    if first > last:
        raise ValueError("The last day is before the first")
    before = f"{row.first_day}..{row.last_day} {row.note}".strip()
    row.first_day, row.last_day, row.note = first, last, (note or "")[:120]
    row.save()
    row.teams.set(teams)
    audit.record(user, row, {"blackout": (before, f"{first}..{last} {note}".strip())})
    return row


def remove(user, row):
    _manager(user)
    audit.record(user, row, {"blackout": (f"{row.first_day}..{row.last_day} {row.note}".strip(), "")})
    row.delete()
```

```python
from leave.models import BankHoliday, Booking, LeaveType
from leave.services import bookings, costing
from leave.services.common import LeaveError
from people.models import Person

def _type():
    return LeaveType.objects.get(name="Bank holiday")


def add(user, day, name):
    if not access.is_manager(user):
        raise PermissionDenied("managers only")
    row, made = BankHoliday.objects.get_or_create(day=day, defaults={"name": (name or "Bank holiday")[:60]})
    if made:
        audit.record(user, row, {"day": ("", f"{day} {row.name}")})
    return row


def remove(user, day):
    if not access.is_manager(user):
        raise PermissionDenied("managers only")
    row = BankHoliday.objects.filter(day=day).first()
    if row:
        audit.record(user, row, {"day": (f"{day} {row.name}", "")})
        row.delete()


def book(user, person, day, seconds):
    """One person's bank holiday at the typed hours (LEAVE-16): a whole-day
    Bank holiday booking whose day is an override noted "bank holiday"."""
    return bookings.book(user, person, _type(), day, day, "whole", note="bank holiday", costs={day: int(seconds)})


def book_many(user, day, hours_by_person):
    booked = skipped = 0
    for pk, seconds in hours_by_person.items():
        person = Person.objects.filter(pk=pk).first()
        if person is None or not access.can_manage(user, person):
            skipped += 1
            continue
        try:
            with transaction.atomic():
                book(user, person, day, seconds)
            booked += 1
        except LeaveError:
            skipped += 1
    return booked, skipped


def suggestions(user, day):
    """[(person, suggested_seconds)] for the manager's current non-GP people, GPs after them at 0."""
    people = access.managed_people(user).current(on=day).filter(display_on_rota=True).order_by("is_gp", "team__display_order", "last_name")
    return [(p, 0 if p.is_gp else costing.suggestion(p, day)) for p in people]
```

```python
EDITABLE = ("name", "colour", "requestable", "paid_choice", "default_paid", "display_order", "draws_from", "on_payroll", "archived")
FIXED_ON_SEEDED = ("draws_from", "on_payroll")


def _manager(user):
    if not access.is_manager(user):
        raise PermissionDenied("managers only")


def add(user, name, colour, draws_from, requestable, paid_choice, on_payroll, default_paid=True):
    _manager(user)
    row = LeaveType.objects.create(name=name.strip()[:60], colour=colour, draws_from=draws_from, requestable=requestable,
                                   paid_choice=paid_choice, on_payroll=on_payroll, default_paid=default_paid,
                                   display_order=(LeaveType.objects.order_by("-display_order").values_list("display_order", flat=True).first() or 0) + 10)
    audit.record(user, row, {"name": ("", row.name)})
    return row


def update(user, row, **fields):
    _manager(user)
    unknown = set(fields) - set(EDITABLE)
    if unknown:
        raise ValueError(f"not editable: {sorted(unknown)}")
    if row.seeded and any(k in fields and fields[k] != getattr(row, k) for k in FIXED_ON_SEEDED):
        raise ValueError("A seeded type keeps what it draws from and how it reaches payroll")
    changes = {}
    for k, v in fields.items():
        before = getattr(row, k)
        if before != v:
            changes[k] = (before, v)
            setattr(row, k, v)
    if changes:
        row.save()
        audit.record(user, row, changes)
    return row


def archive(user, row):
    return update(user, row, archived=True) if not row.archived else row
```

```python
"""Leave as the island reads it: one object per covered or requested day."""

from leave.models import Booking, BookingDay
from people.services import access

PART_MARK = {"whole": "", "am": "½ am", "pm": "½ pm", "times": ""}


def _json(booking, bd, detail):
    out = {"id": booking.pk, "type": booking.type.name, "colour": booking.type.colour, "part": booking.part,
           "label": booking.label if detail else booking.type.name, "status": "pending" if booking.status == Booking.Status.PENDING else "approved"}
    if booking.part == "times":
        out["times"] = f"{booking.start:%H:%M}–{booking.finish:%H:%M}"
    if detail:
        out["description"] = booking.description
        out["paid"] = booking.paid
        out["cost"] = bd.cost_seconds if bd is not None else None
    return out


def leave_for(people, first, last, user):
    me = getattr(user, "person", None)
    manager = access.is_manager(user)
    all_teams = access.is_all_teams(user)
    managed = set(access.managed_teams(user).values_list("pk", flat=True)) if manager and not all_teams else set()
    people = list(people)
    by_pk = {p.pk: p for p in people}

    def detail_for(p):
        return (me is not None and me.pk == p.pk) or all_teams or (manager and p.team_id in managed)

    out = {}
    days = (BookingDay.objects.filter(booking__person__in=people, day__range=(first, last), booking__status__in=Booking.ACTIVE)
            .select_related("booking__type"))
    for bd in days:
        p = by_pk[bd.booking.person_id]
        out.setdefault(p.pk, {})[bd.day.isoformat()] = _json(bd.booking, bd, detail_for(p))
    pending = Booking.objects.filter(person__in=people, status=Booking.Status.PENDING, first_day__lte=last, last_day__gte=first).select_related("type")
    for b in pending:
        p = by_pk[b.person_id]
        for day in b.days():
            if first <= day <= last:
                out.setdefault(p.pk, {}).setdefault(day.isoformat(), _json(b, None, detail_for(p)))
    return out
```

```python
"""REQ-13: a request still waiting after N working days reminds its
managers, once. Working days are Monday to Friday less the bank holidays."""

from datetime import timedelta

from django.utils import timezone

from leave.models import BankHoliday, Booking
from leave.services import notify, settings


def working_days_between(a, b):
    """Working days after `a` up to and including `b`."""
    if b <= a:
        return 0
    holidays = set(BankHoliday.objects.filter(day__range=(a, b)).values_list("day", flat=True))
    n, day = 0, a + timedelta(days=1)
    while day <= b:
        if day.weekday() < 5 and day not in holidays:
            n += 1
        day += timedelta(days=1)
    return n


def due(now=None):
    now = now or timezone.now()
    today = timezone.localtime(now).date()
    limit = settings.get().reminder_working_days
    out = []
    for b in Booking.objects.filter(status__in=(Booking.Status.PENDING, Booking.Status.CANCEL_REQUESTED), reminded_at__isnull=True).select_related("person", "type"):
        since = timezone.localtime(b.cancel_requested_at or b.requested_at).date()
        if working_days_between(since, today) >= limit:
            out.append(b)
    return out


def send(now=None, base_url=""):
    now = now or timezone.now()
    count = 0
    for b in due(now):
        notify.reminder(b, base_url)
        b.reminded_at = now
        b.save(update_fields=["reminded_at"])
        count += 1
    return count
```

```python
"""The booking forms. `BookingForm` serves Add time off (managers, with the
Advanced tab) and Request time off (staff: no person, requestable types
only, no overrides). `costs()` reads the per-day boxes `cost_<iso>` typed
as H:MM or decimal hours into seconds."""

import re
from datetime import date
from decimal import Decimal, InvalidOperation

from django import forms

from leave.models import Booking, LeaveType
from leave.services import hours
from people.models import Person
from people.services import access

HM = re.compile(r"^(\d{1,3}):([0-5]\d)$")


def parse_hours(text):
    text = (text or "").strip()
    if not text:
        return None
    m = HM.match(text)
    if m:
        return int(m.group(1)) * 3600 + int(m.group(2)) * 60
    try:
        return hours.from_hours(Decimal(text.replace("h", "").strip()))
    except (InvalidOperation, ValueError):
        raise forms.ValidationError("Type hours as 7:30 or 7.5") from None


class BookingForm(forms.Form):
    person = forms.ModelChoiceField(Person.objects.none(), required=False)
    type = forms.ModelChoiceField(LeaveType.objects.filter(archived=False))
    description = forms.CharField(max_length=80, required=False, label="Display")
    first_day = forms.DateField(widget=forms.DateInput(attrs={"type": "date"}, format="%Y-%m-%d"), label="First day off")
    last_day = forms.DateField(widget=forms.DateInput(attrs={"type": "date"}, format="%Y-%m-%d"), label="Last day off")
    part = forms.ChoiceField(choices=Booking.Part.choices, initial="whole")
    start = forms.TimeField(required=False, widget=forms.TimeInput(attrs={"type": "time"}, format="%H:%M"))

    staff_note = forms.CharField(max_length=300, required=False, widget=forms.Textarea(attrs={"rows": 2}), label="Note")
    manager_note = forms.CharField(max_length=300, required=False, widget=forms.Textarea(attrs={"rows": 2}), label="Manager notes")

    def __init__(self, user, *args, staff=False, **kwargs):
        super().__init__(*args, **kwargs)
        self.user, self.staff = user, staff
        if staff:
            del self.fields["person"], self.fields["manager_note"], self.fields["paid"]
            self.fields["type"].queryset = LeaveType.objects.filter(archived=False, requestable=True)
        else:
            del self.fields["staff_note"]
            me = getattr(user, "person", None)
            people = access.managed_people(user)
            if me is not None:
                people = people | Person.objects.filter(pk=me.pk)
            self.fields["person"].queryset = people.distinct().order_by("last_name", "first_name")

    def clean(self):
        d = super().clean()
        if d.get("first_day") and d.get("last_day") and d["last_day"] < d["first_day"]:
            self.add_error("last_day", "The last day is before the first")
        if d.get("part") != "whole" and d.get("first_day") != d.get("last_day"):
            self.add_error("part", "A half day or times is one day")
        if d.get("part") == "times" and not (d.get("start") and d.get("finish") and d["start"] < d["finish"]):
            self.add_error("finish", "Give a start before a finish")
        if d.get("part") != "times":
            d["start"] = d["finish"] = None
        return d

    def booking_kwargs(self):
        d = self.cleaned_data
        return {"leave_type": d["type"], "first": d["first_day"], "last": d["last_day"], "part": d["part"],
                "start": d["start"], "finish": d["finish"], "description": d.get("description", ""), "paid": d.get("paid")}

    def costs(self):
        """{day: seconds} for every cost_<iso> box the manager filled."""
        out = {}
        for key, value in self.data.items():
            if key.startswith("cost_") and value.strip():

                    out[date.fromisoformat(key[5:])] = parse_hours(value)
                except (ValueError, forms.ValidationError):
                    self.add_error(None, f"Could not read the hours for {key[5:]}")
```

```python
def _preview(form, booking=None):
    """Costs per day, the balance before and after, and any warning."""
    if not form.is_valid():
        return {}
    kw = form.booking_kwargs()
    person = form.cleaned_data.get("person") or booking.person
    try:
        bookings._check_dates(person, kw["first"], kw["last"], kw["part"], kw["start"], kw["finish"])
        bookings._check_overlap(person, kw["first"], kw["last"], exclude=booking)
    except LeaveError as e:
        return {"error": e.message}
    costs = bookings.preview(person, kw["leave_type"], kw["first"], kw["last"], kw["part"], kw["start"], kw["finish"])
    typed = form.costs()
    days = []
    for c, day in zip(costs, Booking(first_day=kw["first"], last_day=kw["last"]).days()):
        days.append({"day": day, "cost": typed.get(day, c.seconds), "source": c.source, "placeholder": c.placeholder,
                     "hours_known": c.hours_known, "account": c.account, "typed": day in typed})
    total = {}
    for d in days:
        total[d["account"]] = total.get(d["account"], 0) + d["cost"]
    year = years.year_of(person, kw["first"])
    s = balances.statement(person, year)
    account = kw["leave_type"].draws_from
    before = {"annual": s.annual_remaining, "bank_holiday": s.annual_remaining, "toil": s.toil_remaining}.get(account)
    spend = total.get("annual", 0) + total.get("bank_holiday", 0) if account in ("annual", "bank_holiday") else total.get("toil", 0)
    return {"days": days, "total": sum(total.values()), "before": before, "after": None if before is None else before - spend,
            "available": {"annual": s.annual_available, "bank_holiday": s.annual_available, "toil": s.toil_available}.get(account),
            "over": before is not None and spend > {"annual": s.annual_available, "bank_holiday": s.annual_available, "toil": s.toil_available}[account],
            "placeholders": any(d["placeholder"] for d in days), "unknown_hours": any(not d["hours_known"] for d in days),
            "missing_allowance": s.missing and account in ("annual", "bank_holiday")}
```

```python
@login_required
@access.manager_required
def waiting(request):
    people = access.managed_people(request.user)
    rows = (Booking.objects.filter(person__in=people, status__in=(Booking.Status.PENDING, Booking.Status.CANCEL_REQUESTED))
            .select_related("person__team", "type").order_by("requested_at"))
    rows = [b for b in rows if access.can_manage(request.user, b.person)]
    now = timezone.now()
    for b in rows:
        since = b.cancel_requested_at or b.requested_at
        b.waiting_days = (now - since).days
        b.cost = sum(c.seconds for c in bookings.preview(b.person, b.type, b.first_day, b.last_day, b.part, b.start, b.finish)) \
            if b.status == Booking.Status.PENDING else sum(b.booking_days.values_list("cost_seconds", flat=True))

@login_required
def decide(request, pk):

        raise PermissionDenied

        approve = form.cleaned_data["decision"] == "approve"

            if b.status == Booking.Status.CANCEL_REQUESTED:
                bookings.decide_cancel(request.user, b, approve, form.cleaned_data["note"], base_url=base)
            elif approve:
                bookings.approve(request.user, b, form.cleaned_data["note"], base_url=base)
            else:
                bookings.decline(request.user, b, form.cleaned_data["note"], base_url=base)

    account = b.type.draws_from
    before = s.toil_remaining if account == "toil" else s.annual_remaining
    others = (Booking.objects.filter(person__team=b.person.team, status__in=Booking.ACTIVE, first_day__lte=b.last_day, last_day__gte=b.first_day)
              .exclude(person=b.person).select_related("person", "type"))
    return render(request, "leave/decide_dialog.html", {
        "b": b, "form": form, "days": list(zip(b.days(), costs)), "total": total, "before": before,
        "after": before - total if account != "none" and b.status == Booking.Status.PENDING else before, "account": account, "others": others})
```

```python
"""The leave report (REP-02): per person for a range, allowance combined,
adjustments, days booked, deducted, remaining, TOIL; team subtotals; CSV.
Managers see their people, staff their own row. Instances come with spec 4."""

from datetime import date

from django.contrib.auth.decorators import login_required
from django.http import HttpResponse

from django.utils import timezone

from leave.models import Booking, BookingDay
from leave.services import balances, hours, years
from people.services import access

def _dates(request):
    today = timezone.localdate()
    try:
        start = date.fromisoformat(request.GET.get("from", ""))
    except ValueError:
        start = date(today.year, 1, 1)
    try:
        end = date.fromisoformat(request.GET.get("to", ""))
    except ValueError:
        end = date(start.year, 12, 31)
    if end < start:
        start, end = end, start
    return start, end


def rows(user, start, end):
    me = getattr(user, "person", None)
    people = access.managed_people(user) if access.is_manager(user) else (me.__class__.objects.filter(pk=me.pk) if me else [])
    people = [p for p in people.select_related("team").order_by("team__display_order", "team__name", "last_name") if p.start_date <= end and (p.end_date is None or p.end_date >= start)]
    if me is not None and access.is_manager(user) and me not in people:
        people.append(me)
    out = []
    for p in people:
        year = years.year_of(p, start)
        s = balances.statement(p, year)
        days = (BookingDay.objects.filter(booking__person=p, booking__status__in=Booking.ACTIVE, day__range=(start, end)))
        deducted = sum(bd.cost_seconds for bd in days if bd.account in ("annual", "bank_holiday"))
        out.append({"person": p, "team": p.team.name if p.team else "—", "allowance": s.annual_allowance + s.bank_holiday_allowance,
                    "adjustments": s.adjustments["annual"] + s.adjustments["bank_holiday"], "days": days.count(), "deducted": deducted,
                    "remaining": s.annual_remaining, "toil": s.toil_remaining, "missing": s.missing})
    return out


@login_required
def leave_report(request):
    start, end = _dates(request)
    data = rows(request.user, start, end)
    if request.GET.get("download"):
        response = HttpResponse(content_type="text/csv")
        response["Content-Disposition"] = f'attachment; filename="leave-{start.isoformat()}-{end.isoformat()}.csv"'
        w = csv_safe.Writer(response)
        w.writerow(["Name", "Team", "Allowance", "Adjustments", "Days", "Deducted", "Remaining", "TOIL"])
        for r in data:
            w.writerow([r["person"].name, r["team"], hours.fmt(r["allowance"]), hours.fmt(r["adjustments"]), r["days"], hours.fmt(r["deducted"]), hours.fmt(r["remaining"]), hours.fmt(r["toil"])])
        return response
    teams = []
    for r in data:
        if not teams or teams[-1]["team"] != r["team"]:
            teams.append({"team": r["team"], "rows": [], "deducted": 0, "remaining": 0})
        teams[-1]["rows"].append(r)
        teams[-1]["deducted"] += r["deducted"]
        teams[-1]["remaining"] += r["remaining"]
    return render(request, "leave/report.html", {"page_title": "Leave", "teams": teams, "start": start, "end": end})
```

```python
"""Approved GP leave for the rota app (spec section 8). A timed booking is
reported as the half it falls in. Never a description, a note or a pk."""

from datetime import time

from leave.models import Booking

NOON = time(13, 0)


def part_of(b):
    if b.part != "times":
        return b.part
    if b.finish <= NOON:
        return "am"
    if b.start >= NOON:
        return "pm"
    return "whole"


def records(start, end):
    rows = (Booking.objects.filter(person__is_gp=True, status__in=Booking.ACTIVE, first_day__lte=end, last_day__gte=start)
            .exclude(person__email="").select_related("person", "type").order_by("first_day", "person__email", "pk"))
    return [{"email": b.person.email, "first_day": b.first_day.isoformat(), "last_day": b.last_day.isoformat(), "part": part_of(b), "type": b.type.name}
            for b in rows]
```

```python
"""GET /api/v1/leave?from=YYYY-MM-DD&to=YYYY-MM-DD → approved GP leave in the
range, for the GP rota app. Read-only; the token is checked by api_auth."""

from datetime import date

from django.http import JsonResponse
from django.utils import timezone

from leave.api_auth import token_required
from leave.services import feed

MAX_DAYS = 1100


def _bad(message):
    return JsonResponse({"error": message}, status=400)


@token_required
def leave_feed(request):
    try:
        start = date.fromisoformat(request.GET.get("from", ""))
        end = date.fromisoformat(request.GET.get("to", ""))
    except ValueError:
        return _bad("from and to must be dates (YYYY-MM-DD)")
    if end < start:
        return _bad("to is before from")
    if (end - start).days > MAX_DAYS:
        return _bad(f"the range is over {MAX_DAYS} days")
    return JsonResponse({"from": start.isoformat(), "to": end.isoformat(), "generated_at": timezone.now().isoformat(), "leave": feed.records(start, end)})
```

```python
"""A read-only client for Shift Central's GP leave feed, on the standard
library: https only outside DEBUG, no redirects, the token never logged,
the body never logged."""

import json
import logging
import urllib.error
import urllib.request
from urllib.parse import urlencode, urlparse

from django.conf import settings

log = logging.getLogger("rota.shift_central")


class _RefuseRedirects(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None


_OPENER = urllib.request.build_opener(_RefuseRedirects)


class ShiftCentralError(Exception):
    pass


class ShiftCentralClient:
    def __init__(self, base_url, token, *, opener=None, timeout=10):
        self.base_url = base_url.rstrip("/")
        self._token = token
        self._open = opener or (lambda req: _OPENER.open(req, timeout=timeout))

    def leave(self, start, end):
        url = f"{self.base_url}/api/v1/leave?" + urlencode({"from": start.isoformat(), "to": end.isoformat()})
        if urlparse(url).scheme != "https" and not settings.DEBUG:
            raise ShiftCentralError("SHIFT_CENTRAL_URL is not https; the token was not sent")
        req = urllib.request.Request(url, method="GET", headers={"Accept": "application/json", "Authorization": f"Bearer {self._token}"})
        try:
            with self._open(req) as resp:
                raw = resp.read()
        except urllib.error.HTTPError as e:
            log.warning("shift central leave -> %s", e.code)
            raise ShiftCentralError(f"Shift Central returned {e.code} for leave") from None
        except (urllib.error.URLError, OSError) as e:
            log.warning("shift central unreachable: %s", e.__class__.__name__)
            raise ShiftCentralError("Shift Central unreachable") from None
        try:
            body = json.loads(raw)
        except ValueError:
            raise ShiftCentralError("Shift Central returned a non-JSON body for leave") from None
        if not isinstance(body, dict) or not isinstance(body.get("leave"), list):
            raise ShiftCentralError("Shift Central's leave response has no 'leave' list")
        return body


def from_settings():
    if not settings.SHIFT_CENTRAL_URL or not settings.SHIFT_CENTRAL_TOKEN:
        return None
    return ShiftCentralClient(settings.SHIFT_CENTRAL_URL, settings.SHIFT_CENTRAL_TOKEN)
```

`rota/services/shift_central/sync.py`:

```python
"""One sync: fetch the window, match each record to a clinician by the
login email (lowercased), turn parts into the rota's Span, replace the
TimeOff table in full. Never raises; a failed run keeps the previous rows.
Emails are record values: in `detail`, never in `error` or a log line."""

import logging
from datetime import date, timedelta

from django.db import transaction
from django.utils import timezone

from rota.models import Clinician, TimeOff, TimeOffSyncRun
from rota.services.shift_central.client import ShiftCentralError
from rota.services.time_off import Span

log = logging.getLogger("rota.shift_central")
HISTORY_DAYS, HORIZON_DAYS = 365, 730


class BadRecord(Exception):
    pass


def window(today=None):
    today = today or timezone.localdate()
    return today - timedelta(days=HISTORY_DAYS), today + timedelta(days=HORIZON_DAYS)


def _span(record, position):
    try:
        first, last = date.fromisoformat(record["first_day"]), date.fromisoformat(record["last_day"])
        part = str(record["part"])
        if part not in ("whole", "am", "pm") or last < first or (part != "whole" and first != last):
            raise ValueError
    except (KeyError, TypeError, ValueError, AttributeError):
        raise BadRecord(f"record {position} in the feed: missing or bad email, days or part") from None
    return Span(first, last, half_start=(part == "pm"), half_start_am_pm="PM" if part == "pm" else "",
                half_end=(part == "am"), half_end_am_pm="AM" if part == "am" else "")


def _clinicians():
    out = {}
    for c in Clinician.objects.filter(active=True).exclude(user=None).select_related("user").order_by("pk"):
        if c.user.email:
            out.setdefault(c.user.email.lower(), c)
    return out


def run(client, *, dry_run=False, now=None):
    now = now or timezone.now()
    result = TimeOffSyncRun(started=now)
    try:
        return _run(client, result, dry_run=dry_run, today=timezone.localtime(now).date())
    except Exception as e:
        log.warning("shift central sync failed with %s", type(e).__name__)
        result.ok, result.error, result.finished = False, f"{type(e).__name__}: {e}"[:500], timezone.now()
        if not dry_run:
            result.save()
        return result


def _run(client, result, *, dry_run, today):
    start, end = window(today)
    try:
        payload = client.leave(start, end)
    except ShiftCentralError as e:
        result.error, result.finished = str(e), timezone.now()
        if not dry_run:
            result.save()
        return result
    by_email = _clinicians()
    rows, keys, unmatched, matched = [], set(), set(), set()
    outside = 0
    for position, record in enumerate(payload["leave"], start=1):
        try:
            email = str(record["email"]).strip().lower()
        except (KeyError, TypeError, AttributeError):
            raise BadRecord(f"record {position} in the feed: missing email") from None
        span = _span(record, position)
        if span.end_date < start or span.start_date > end:
            outside += 1
            continue
        clinician = by_email.get(email)
        if clinician is None:
            unmatched.add(email)
            continue
        key = (clinician.pk, span.start_date, span.end_date, span.half_start, span.half_start_am_pm, span.half_end, span.half_end_am_pm)
        if key in keys:
            continue
        keys.add(key)
        matched.add(clinician.pk)
        rows.append(TimeOff(clinician=clinician, start_date=span.start_date, end_date=span.end_date, half_start=span.half_start,
                            half_start_am_pm=span.half_start_am_pm or "", half_end=span.half_end, half_end_am_pm=span.half_end_am_pm or "",
                            reason=str(record.get("type") or "")[:100], source_ids=span.start_date.isoformat()))
    result.n_records, result.n_matched, result.n_unmatched, result.n_outside = len(payload["leave"]), len(matched), len(unmatched), outside
    result.detail = {"unmatched": sorted(unmatched)}
    result.ok, result.finished = True, timezone.now()
    if dry_run:
        return result
    with transaction.atomic():
        TimeOff.objects.all().delete()
        TimeOff.objects.bulk_create(rows)
        result.save()
    return result


def unmatched_emails():
    last = TimeOffSyncRun.objects.filter(ok=True).first()
    return list((last.detail or {}).get("unmatched", [])) if last else []
```

```python
it, see the shift back. Signs in with a password as test_grid does."""

import pytest
from playwright.sync_api import expect

from tests.factories import make_allowance, make_entry, make_person, make_team, make_team_manager, make_user_for

pytestmark = [pytest.mark.django_db(transaction=True), pytest.mark.e2e]
MON = "2027-03-01"


@pytest.fixture
def manager(live_server):
    from datetime import date, time
    from decimal import Decimal
    team = make_team("Reception")
    lead = make_person(first_name="Lead", team=team)
    make_team_manager(lead, team)
    user = make_user_for(lead, password="pw")
    nina = make_person(first_name="Nina", team=team, start_date=date(2020, 1, 6), weekly_hours=Decimal("37.5"), days_per_week=5)
    make_allowance(nina, date(2027, 1, 1), Decimal("172.5"), 60)
    make_entry(nina, date(2027, 3, 1), start=time(9), finish=time(17), break_minutes=30)
    return user


def _sign_in(page, live_server, user):
    page.goto(f"{live_server.url}/accounts/login/?next=/rota/?from={MON}")
    page.fill("input[name=username]", user.email)
    page.fill("input[name=password]", "pw")
    page.click("button[type=submit]")
    page.wait_for_selector("table.rota-grid")


def test_book_from_the_menu_then_cancel(page, live_server, manager):
    _sign_in(page, live_server, manager)
    nina_mon = page.locator("tr:has(th.rota-name:has-text('Nina')) td").first
    expect(nina_mon.locator(".tile-shift")).to_have_count(1)
    nina_mon.click(button="right")
    page.click(".rota-menu >> text=Time off…")
    page.wait_for_selector("#dialog form")
    page.select_option("#dialog select[name=type]", label="Holiday")
    page.click("#dialog button.btn-dark")
    expect(nina_mon.locator(".tile-leave")).to_have_text("Holiday")
    expect(nina_mon.locator(".tile-shift")).to_have_count(0)
    nina_mon.click(button="right")
    page.click(".rota-menu >> text=Cancel time off")
    page.wait_for_selector("#dialog form")
    page.click("#dialog button.btn-dark")
    expect(nina_mon.locator(".tile-shift")).to_have_count(1)
    expect(nina_mon.locator(".tile-leave")).to_have_count(0)
```
