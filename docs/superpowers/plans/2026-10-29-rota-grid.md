# AMG Shift Central: Rota Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The FindMyShift-style rota grid for every team: shifts as ordered cell items, a Preact island for selection, free-typing, drag, block copy and paste, the right-click menu and appearance; templates, overtime marks, "Notify staff" by email, the hours report, "Who's in today", and GP sessions shown read-only from the GP rota app's new feed.

**Architecture:** A new `shifts` app holds `Entry` (one row per item in a person-day cell), `Template`, `DayChange` (what notify compares against), `GpSession` (replaced wholesale by a 15-minute sync) and `GridOptions`; every write goes through `shifts/services/entries.py`, which checks `access.can_manage` per person, records a `DayChange` before a day's first unnotified change and audits each cell as one `AuditEntry`. The grid page mounts one island (`frontend/src/rota-grid/`) that draws from `GET /rota/api/window/` and posts JSON mutations; every pop-up stays a Django template fetched into `#dialog` by the Foundation's `modal.js`, which learns one new answer, `{"refresh": true}`. A `messaging` app owns `Outbox` and `send()`. The GP rota app gains `GET /api/v1/sessions` behind a bearer token, in Practice HR's `api/auth.py` pattern.

**Tech Stack:** Python 3.13, Django 5.2.17, pytest 9 + pytest-django 4.12, pytest-playwright (new), ruff 0.16.6; Node 22, Vite 6, Preact 10, TypeScript 5, vitest (new). No new runtime dependency on the VPS.

**Spec:** `docs/superpowers/specs/2026-10-29-rota-grid-design.md` — read it first, with the Foundation spec it builds on (`2026-10-29-foundation-design.md`) and the requirements it cites (`docs/requirements/02-team-rotas.md`, `03-findmyshift-feature-review.md`).

## Global Constraints

- Everything in the Foundation plan's Global Constraints still holds: Django 5.2 LTS, Python 3.13, SQLite WAL; secrets from the environment only, nothing secret in a file or a log line; every colour from `static/css/tokens.css`; frontend source in `frontend/`, built output in `static/dist/` committed and checked by CI; CSP on every page, so no inline scripts or handlers; `TIME_ZONE = "Europe/London"`.
- **All writes to `shifts` go through `shifts/services/`**; views and the API call services, never models. Every change writes `AuditEntry` rows through `people.services.audit.record` with `model="shifts.entry"`, `object_id` the person's pk, `field` `cell` / `appearance` / `notified`, and the note `"{Mon 2 Mar 2027} · {person.name}"` built by `render.audit_note(person, day)`.
- **The server parses.** `shifts/services/parse.py` is what is stored; `frontend/src/rota-grid/parser.ts` is a live preview. Both read the same cases file `frontend/src/rota-grid/parser.cases.json`.
- **The API never redirects.** Signed out → 401 JSON `{"error": "signed out"}`; refused → 403 JSON `{"error": "…"}`; bad input → 400 JSON `{"error": "…"}`.
- **No record's values in a log line or a `SyncRun.message`.** The GP feed is logged by counts.
- Times are shown `08:00–16:15` (en dash) on screen and written `08:00-16:15` (hyphen) in canonical cell text; durations as `7 h 15 min` (`render.duration`). The week starts on Monday.
- Code style as the Foundation: module docstrings that say why, comments for non-obvious choices, no type-annotation ceremony in Python, tests named as sentences. Commit after every task, `Area: what changed`, with the session's attribution lines. `ruff check .`, `python -m pytest -q`, and for frontend tasks `npm run check && npm test && npm run build` in `frontend/`, all clean before every commit; **the rebuilt `static/dist/` is committed with the source that produced it.**
- Tests never reach the network or a mail relay: `EMAIL_HOST` is empty under pytest, so `messaging.send()` uses the locmem backend pytest-django installs.

```python
"""One row per item in a cell. A cell is one person on one day and, as in
FindMyShift, holds several items in order: shifts, comments, separators
(spec, section 2). ROTA-06's overtime is a second shift in the same cell."""

from datetime import datetime, timedelta

from django.conf import settings
from django.db import models
from django.db.models import Q


class Entry(models.Model):
    class Kind(models.TextChoices):
        SHIFT = "shift"
        COMMENT = "comment"
        SEPARATOR = "separator"

    class Overtime(models.TextChoices):
        NONE = "", "None"
        PAID = "paid", "Overtime – paid"
        TOIL = "toil", "Overtime – TOIL"

    BREAKS = (0, 15, 30, 45, 60)

    person = models.ForeignKey("people.Person", on_delete=models.PROTECT, related_name="entries")
    day = models.DateField()
    position = models.PositiveSmallIntegerField(default=0)
    kind = models.CharField(max_length=10, choices=Kind.choices, default=Kind.SHIFT)
    start = models.TimeField(null=True, blank=True)
    finish = models.TimeField(null=True, blank=True)
    break_minutes = models.PositiveSmallIntegerField(default=0)
    department = models.ForeignKey("people.Department", null=True, blank=True,
                                   on_delete=models.PROTECT, related_name="entries")
    text = models.CharField(max_length=200, blank=True, default="")
    overtime = models.CharField(max_length=4, choices=Overtime.choices, blank=True, default="")
    wfh = models.BooleanField(default=False)
    # bg, fg (hex), bold, italic, underline, strike, wrap (bool), size (sm/md/lg).
    # Empty means the department's colour and the defaults (ROTA-04a).
    appearance = models.JSONField(default=dict, blank=True)
    created_by = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, blank=True,
                                   on_delete=models.SET_NULL, related_name="+")
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ["day", "person_id", "position"]
        verbose_name_plural = "entries"
        constraints = [
            models.UniqueConstraint(fields=["person", "day", "position"], name="one_item_per_slot"),
            models.CheckConstraint(
                condition=(Q(kind="shift", start__isnull=False, finish__isnull=False)
                           | (~Q(kind="shift") & Q(start__isnull=True, finish__isnull=True))),
                name="shift_has_times"),
        ]
        indexes = [models.Index(fields=["person", "day"])]

    def __str__(self):
        return f"{self.person_id} {self.day} #{self.position} {self.kind}"

    @property
    def hours(self):
        """finish − start − break for a shift, zero otherwise. Overtime is
        not subtracted here: readers that must leave it out filter on the
        mark (LEAVE-05, 23)."""
        if self.kind != self.Kind.SHIFT or self.start is None or self.finish is None:
            return timedelta(0)
        anchor = datetime(2000, 1, 1)
        worked = datetime.combine(anchor, self.finish) - datetime.combine(anchor, self.start)
        return max(worked - timedelta(minutes=self.break_minutes), timedelta(0))
```

`messaging/services.py`:

```python
"""The one sender. Writes the Outbox row first, so a message is on record
whether or not the relay takes it; never raises; never puts a body or an
address in a log line or in `error` (the exception's class and its first
line are enough to find the cause in the journal)."""

import logging

from django.core.mail import send_mail
from django.utils import timezone

from .models import Outbox

log = logging.getLogger("messaging")


def send(person, subject, body):
    row = Outbox.objects.create(to_person=person, to_email=person.email or "", subject=subject, body=body)
    if not person.email:
        row.error = "no email address"
        row.save(update_fields=["error"])
        return row
    try:
        send_mail(subject, body, None, [person.email], fail_silently=False)
    except Exception as e:  # anything the backend raises is a failed send, not a crash
        row.error = f"{e.__class__.__name__}: {str(e).splitlines()[0][:200]}"[:300]
        log.warning("send failed to person %s: %s", person.pk, e.__class__.__name__)
    else:
        row.sent_at = timezone.now()
    row.save(update_fields=["sent_at", "error"])
    return row
```

`shifts/services/parse.py`:

```python
"""Free-typed cell text into items (spec, section 5). A line with a time
range is a shift; from the rest a break, WFH, an overtime word and a
department name are pulled out, and what remains is the comment. A line
without a range is a comment; three or more hyphens alone, a separator.
Never raises: whatever cannot be read is kept as text, so nothing typed is
lost. frontend/src/rota-grid/parser.ts mirrors this for the live preview;
parser.cases.json is the shared table both are tested against."""

import re
from datetime import time

from shifts.models import Entry

_SIDE = r"(?P<{p}h>\d{{1,2}})(?:[:.]?(?P<{p}m>\d{{2}}))?\s*(?P<{p}ap>am|pm)?"
RANGE = re.compile(
    r"(?<![\d:.])" + _SIDE.format(p="a") + r"\s*(?:-|–|—|to|until)\s*" + _SIDE.format(p="b") + r"(?![\d:.])",
    re.IGNORECASE)
SEPARATOR = re.compile(r"^\s*-{3,}\s*$")
BREAK = re.compile(
    r"(?<!\w)(?:(?P<h>\d+)\s*(?:hours?|hrs?|h)(?:\s+break)?|(?P<m>\d+)\s*(?:minutes?|mins?|m)(?:\s+break)?|break\s+(?P<n>\d+))(?!\w)",
    re.IGNORECASE)
WFH = re.compile(r"(?<!\w)wfh(?!\w)", re.IGNORECASE)
TOIL = re.compile(r"(?<!\w)toil(?!\w)", re.IGNORECASE)
PAID = re.compile(r"(?<!\w)(?:ot paid|overtime paid|paid overtime|ot)(?!\w)", re.IGNORECASE)


def _time(h, m, ap):
    h, m = int(h), int(m or 0)
    if h > 23 or m > 59:
        return None
    ap = (ap or "").lower()
    if ap == "pm" and h < 12:
        h += 12
    if ap == "am" and h == 12:
        h = 0
    if ap and h > 23:
        return None
    return time(h, m)


def _range(match):
    """The two times, or None. A finish with no am/pm that is not after the
    start is read as pm (8-4 is 08:00–16:00); if it still is not after the
    start, the line is not a shift."""
    start = _time(match["ah"], match["am"], match["aap"])
    finish = _time(match["bh"], match["bm"], match["bap"])
    if start is None or finish is None:
        return None
    if not match["bap"] and finish <= start and finish.hour < 12:
        finish = time(finish.hour + 12, finish.minute)
    if finish <= start:
        return None
    return start, finish


def _break(rest):
    """The break in minutes and the text without it, or 0 and the text
    unchanged when the length is not one ROTA-01 allows (a '20 min break'
    stays in the comment for a manager to see)."""
    for m in BREAK.finditer(rest):
        minutes = int(m["h"]) * 60 if m["h"] else int(m["m"] or m["n"])
        if minutes in Entry.BREAKS:
            return minutes, rest[:m.start()] + " " + rest[m.end():]
    return 0, rest


def _department(rest, departments):
    """The longest department name present as a whole phrase, and the text
    without it."""
    for dept in sorted(departments, key=lambda d: -len(d.name)):
        m = re.search(r"(?<!\w)" + re.escape(dept.name) + r"(?!\w)", rest, re.IGNORECASE)
        if m:
            return dept, rest[:m.start()] + " " + rest[m.end():]
    return None, rest


def _comment(text):
    return " ".join(text.split())[:200]


def line(text, departments):
    """One line of cell text as an item dict."""
    if SEPARATOR.match(text):
        return {"kind": "separator"}
    m = RANGE.search(text)
    times = _range(m) if m else None
    if times is None:
        return {"kind": "comment", "text": _comment(text)}
    rest = text[:m.start()] + " " + text[m.end():]
    break_minutes, rest = _break(rest)
    wfh = bool(WFH.search(rest))
    rest = WFH.sub(" ", rest)
    overtime = ""
    if TOIL.search(rest):
        overtime, rest = "toil", TOIL.sub(" ", rest, count=1)
    elif PAID.search(rest):
        overtime, rest = "paid", PAID.sub(" ", rest, count=1)
    department, rest = _department(rest, departments)
    return {"kind": "shift", "start": times[0], "finish": times[1], "break_minutes": break_minutes,
            "department": department, "text": _comment(rest), "wfh": wfh, "overtime": overtime}


def cell(text, departments):
    """Every non-blank line of a cell's text, in order."""
    departments = list(departments)
    return [line(raw, departments) for raw in text.splitlines() if raw.strip()]
```

`shifts/services/render.py`:

```python
"""Items and cells as text: the canonical line parse.py reads back, the
day's text DayChange and the audit hold, and durations as LEAVE-04 shows
them."""

from shifts.models import Entry

_OVERTIME = {"paid": "OT paid", "toil": "TOIL"}


def time_hm(t):
    return t.strftime("%H:%M")


def _get(item, key, default=None):
    return item.get(key, default) if isinstance(item, dict) else getattr(item, key, default)


def line(item):
    """A shift as '08:00-16:15 1 hour break Reception PMC WFH TOIL comment';
    a comment as its text; a separator as '---'. Hyphen, not en dash, so
    the line re-parses; the island shows the dash."""
    kind = _get(item, "kind")
    if kind == "separator":
        return "---"
    if kind == "comment":
        return _get(item, "text", "")
    parts = [f"{time_hm(_get(item, 'start'))}-{time_hm(_get(item, 'finish'))}"]
    minutes = _get(item, "break_minutes", 0)
    if minutes == 60:
        parts.append("1 hour break")
    elif minutes:
        parts.append(f"{minutes} min break")
    dept = _get(item, "department")
    if dept is not None:
        parts.append(dept.name)
    if _get(item, "wfh"):
        parts.append("WFH")
    if _get(item, "overtime"):
        parts.append(_OVERTIME[_get(item, "overtime")])
    if _get(item, "text"):
        parts.append(_get(item, "text"))
    return " ".join(parts)


def cell_text(entries):
    return "\n".join(line(e) for e in entries)


def day_text(person, day):
    rows = Entry.objects.filter(person=person, day=day).select_related("department").order_by("position")
    return " / ".join(line(e) for e in rows) or "no shift"


def duration(td):
    minutes = int(td.total_seconds() // 60)
    h, m = divmod(minutes, 60)
    if h and m:
        return f"{h} h {m} min"
    if h:
        return f"{h} h"
    return f"{m} min"


def audit_note(person, day):
    return f"{day:%a} {day.day} {day:%b %Y} · {person.name}"
```

```python
"""The one writer of cells (spec, section 4). Every function here checks
access.can_manage for each person touched before any write, records a
DayChange before a day's first unnotified change, applies the change and
audits one row per cell, all in one transaction. Partial writes never
happen: a refusal raises before the transaction opens."""

import re
from dataclasses import dataclass, field
from datetime import date, datetime, time

from django.core.exceptions import PermissionDenied
from django.db import transaction

from people.models import Department, Person
from people.services import access, audit
from shifts.models import DayChange, Entry
from shifts.services import parse, render

HEX = re.compile(r"^#[0-9A-Fa-f]{6}$")
APPEARANCE_BOOLS = ("bold", "italic", "underline", "strike", "wrap")
SIZES = ("sm", "md", "lg")


@dataclass
class Changed:
    cells: dict = field(default_factory=dict)   # {person_id: {date: [Entry]}}
    skipped: int = 0

    def add(self, person, day, rows):
        self.cells.setdefault(person.pk, {})[day] = rows


# --- input -----------------------------------------------------------------

def clean_appearance(raw):
    if not isinstance(raw, dict):
        raise ValueError("appearance must be an object")
    out = {}
    for key in ("bg", "fg"):
        if raw.get(key):
            if not isinstance(raw[key], str) or not HEX.match(raw[key]):
                raise ValueError(f"{key} must be a hex colour")
            out[key] = raw[key].upper()
    for key in APPEARANCE_BOOLS:
        if raw.get(key):
            out[key] = True
    if raw.get("size"):
        if raw["size"] not in SIZES:
            raise ValueError("size must be sm, md or lg")
        if raw["size"] != "md":
            out["size"] = raw["size"]
    return out


def _hm(value, name):
    try:
        return time.fromisoformat(value) if isinstance(value, str) else value
    except ValueError:
        raise ValueError(f"{name} is not a time") from None


def _clean_item(raw, departments):
    """A JSON-shaped item as the fields an Entry takes."""
    kind = raw.get("kind", "shift")
    if kind not in Entry.Kind.values:
        raise ValueError("unknown item kind")
    item = {"kind": kind, "appearance": clean_appearance(raw.get("appearance") or {})}
    if kind == Entry.Kind.SEPARATOR:
        return item
    item["text"] = str(raw.get("text") or "")[:200]
    if kind == Entry.Kind.COMMENT:
        return item
    start, finish = _hm(raw.get("start"), "start"), _hm(raw.get("finish"), "finish")
    if not isinstance(start, time) or not isinstance(finish, time) or finish <= start:
        raise ValueError("a shift needs a start and a later finish")
    item.update(start=start, finish=finish)
    item["break_minutes"] = int(raw.get("break_minutes") or 0)
    if item["break_minutes"] not in Entry.BREAKS:
        raise ValueError("the break must be 15, 30, 45 or 60 minutes")
    dept = raw.get("department")
    if dept not in (None, ""):
        dept = departments.get(int(dept)) if str(dept).isdigit() else None
        if dept is None:
            raise ValueError("unknown department")
    item["department"] = dept or None
    item["overtime"] = raw.get("overtime") or ""
    if item["overtime"] not in Entry.Overtime.values:
        raise ValueError("overtime must be paid or TOIL")
    item["wfh"] = bool(raw.get("wfh"))
    return item


def _from_parsed(parsed):
    """parse.cell's dicts as _clean_item's output (same keys, Department
    objects already resolved)."""
    item = dict(parsed)
    item.setdefault("appearance", {})
    item.setdefault("text", "")
    return item


def _departments():
    return {d.pk: d for d in Department.objects.all()}


# --- access and bookkeeping -----------------------------------------------

def _people(user, ids):
    """The people for these ids, each one the user may manage, else refuse."""
    people = {p.pk: p for p in Person.objects.filter(pk__in=set(ids))}
    for pk in set(ids):
        person = people.get(pk)
        if person is None or not access.can_manage(user, person):
            raise PermissionDenied("you can't edit this person's rota")
    return people


def _check(user, person):
    if not access.can_manage(user, person):
        raise PermissionDenied("you can't edit this person's rota")


def _touch(person, day):
    DayChange.objects.get_or_create(person=person, day=day,
                                    defaults={"before": render.day_text(person, day)})


def _write(user, person, day, items, keep_appearance=True):
    """Replace the cell's items. The appearance of an item in the same slot
    with the same kind survives a rewrite (a retyped time keeps its colour).
    Audits the cell as one row. Call inside a transaction, after _check."""
    old = list(Entry.objects.filter(person=person, day=day).select_related("department").order_by("position"))
    before = " / ".join(render.line(e) for e in old) or "no shift"
    _touch(person, day)
    Entry.objects.filter(person=person, day=day).delete()
    rows = []
    for position, item in enumerate(items):
        fields = dict(item)
        if keep_appearance and not fields.get("appearance") and position < len(old) \
                and old[position].kind == fields["kind"]:
            fields["appearance"] = old[position].appearance
        rows.append(Entry(person=person, day=day, position=position, created_by=user, **fields))
    Entry.objects.bulk_create(rows)
    rows = list(Entry.objects.filter(person=person, day=day).select_related("department").order_by("position"))
    after = " / ".join(render.line(e) for e in rows) or "no shift"
    audit.record_as(user, "shifts.entry", person.pk, {"cell": (before, after)}, note=render.audit_note(person, day))
    return rows


# --- the API's verbs --------------------------------------------------------

def set_cell_text(user, person, day, text):
    _check(user, person)
    offered = Department.objects.filter(archived=False)
    items = [_from_parsed(p) for p in parse.cell(text, offered)]
    with transaction.atomic():
        return _write(user, person, day, items)


def set_cell(user, person, day, items):
    _check(user, person)
    departments = _departments()
    cleaned = [_clean_item(raw, departments) for raw in items]
    with transaction.atomic():
        return _write(user, person, day, cleaned, keep_appearance=False)


PATCHABLE = ("department", "break_minutes", "overtime", "wfh", "appearance", "text")


def patch(user, entry, **fields):
    unknown = set(fields) - set(PATCHABLE)
    if unknown:
        raise ValueError(f"not patchable: {sorted(unknown)}")
    _check(user, entry.person)
    if "appearance" in fields:
        fields["appearance"] = clean_appearance(fields["appearance"] or {})
    if "department" in fields:
        dept = fields["department"]
        fields["department"] = None if dept in (None, "") else Department.objects.filter(pk=dept).first()
        if dept not in (None, "") and fields["department"] is None:
            raise ValueError("unknown department")
    if "break_minutes" in fields and int(fields["break_minutes"]) not in Entry.BREAKS:
        raise ValueError("the break must be 15, 30, 45 or 60 minutes")
    if "overtime" in fields and (fields["overtime"] or "") not in Entry.Overtime.values:
        raise ValueError("overtime must be paid or TOIL")
    if entry.kind != Entry.Kind.SHIFT and set(fields) & {"department", "break_minutes", "overtime", "wfh"}:
        raise ValueError("only a shift takes a department, break, overtime or WFH")
    with transaction.atomic():
        before_line = render.line(entry)
        if set(fields) == {"appearance"}:
            entry.appearance = fields["appearance"]
            entry.save(update_fields=["appearance", "updated_at"])
            audit.record_as(user, "shifts.entry", entry.person.pk, {"appearance": ("", str(entry.appearance))},
                            note=f"{render.audit_note(entry.person, entry.day)} · {before_line}")
            return entry
        before = render.day_text(entry.person, entry.day)
        _touch(entry.person, entry.day)
        for name, value in fields.items():
            setattr(entry, name, value if name != "text" else str(value or "")[:200])
        entry.save()
        audit.record_as(user, "shifts.entry", entry.person.pk, {"cell": (before, render.day_text(entry.person, entry.day))},
                        note=render.audit_note(entry.person, entry.day))
        return entry


def _cells(cells):
    return [(int(p), d if isinstance(d, date) else date.fromisoformat(d)) for p, d in cells]


def clear(user, cells):
    cells = _cells(cells)
    people = _people(user, [p for p, _ in cells])
    changed = Changed()
    with transaction.atomic():
        for pk, day in cells:
            changed.add(people[pk], day, _write(user, people[pk], day, []))
    return changed


def _snapshot(entry):
    return {"kind": entry.kind, "start": entry.start, "finish": entry.finish,
            "break_minutes": entry.break_minutes, "department": entry.department,
            "text": entry.text, "wfh": entry.wfh, "overtime": entry.overtime,
            "appearance": dict(entry.appearance)}


def _items_of(person, day):
    return [_snapshot(e) for e in Entry.objects.filter(person=person, day=day)
            .select_related("department").order_by("position")]


def move(user, cells, days, rows, copy, row_order):
    """Translate a selection by (days, rows) over the grid's row order.
    Targets are checked before anything is written; a target off the row
    list or on a row the user may not edit refuses the whole move."""
    cells = _cells(cells)
    row_order = [int(p) for p in row_order]
    targets = []
    for pk, day in cells:
        try:
            idx = row_order.index(pk) + rows
        except ValueError:
            raise ValueError("a moved row is not on the grid") from None
        if idx < 0 or idx >= len(row_order):
            raise ValueError("the move goes off the grid")
        targets.append((row_order[idx], day + timedelta(days=days)))
    people = _people(user, [p for p, _ in cells] + [p for p, _ in targets])
    changed = Changed()
    with transaction.atomic():
        snapshots = {(pk, day): _items_of(people[pk], day) for pk, day in cells}
        if not copy:
            for pk, day in cells:
                changed.add(people[pk], day, _write(user, people[pk], day, []))
        for (pk, day), (tpk, tday) in zip(cells, targets):
            changed.add(people[tpk], tday, _write(user, people[tpk], tday, snapshots[(pk, day)], keep_appearance=False))
    return changed


def paste(user, anchor, block, mode, row_order):
    """Write a clipboard block with its top-left at the anchor. Rows below
    the end of the grid, or the user may not edit, are skipped and counted;
    nothing else about the paste is refused."""
    if mode not in ("replace", "add"):
        raise ValueError("paste mode must be replace or add")
    anchor_pk, anchor_day = _cells([anchor])[0]
    row_order = [int(p) for p in row_order]
    if anchor_pk not in row_order:
        raise ValueError("the anchor is not on the grid")
    rows = block.get("rows") if isinstance(block, dict) else None
    if not isinstance(rows, list):
        raise ValueError("the block has no rows")
    departments = _departments()
    start = row_order.index(anchor_pk)
    planned, skipped = [], 0
    people = {p.pk: p for p in Person.objects.filter(pk__in=row_order[start:start + len(rows)])}
    for r, cells in enumerate(rows):
        if start + r >= len(row_order):
            skipped += 1
            continue
        person = people.get(row_order[start + r])
        if person is None or not access.can_manage(user, person):
            skipped += 1
            continue
        for d, items in enumerate(cells if isinstance(cells, list) else []):
            planned.append((person, anchor_day + timedelta(days=d), [_clean_item(i, departments) for i in items]))
    changed = Changed(skipped=skipped)
    with transaction.atomic():
        for person, day, items in planned:
            if mode == "add":
                items = _items_of(person, day) + items
            changed.add(person, day, _write(user, person, day, items, keep_appearance=False))
    return changed


def replace(user, cells, find, replacement, match_case):
    """Find and replace over each item's canonical line; a changed line is
    re-parsed, so replacing a department name re-tags the shift."""
    if not find:
        raise ValueError("nothing to find")
    cells = _cells(cells)
    people = _people(user, [p for p, _ in cells])
    pattern = re.compile(re.escape(find), 0 if match_case else re.IGNORECASE)
    offered = list(Department.objects.filter(archived=False))
    changed = Changed()
    with transaction.atomic():
        for pk, day in cells:
            person = people[pk]
            old = list(Entry.objects.filter(person=person, day=day).select_related("department").order_by("position"))
            items, touched = [], False
            for e in old:
                line = render.line(e)
                new = pattern.sub(replacement, line)
                if new == line:
                    items.append(_snapshot(e))
                    continue
                touched = True
                item = _from_parsed(parse.line(new, offered))
                item["appearance"] = dict(e.appearance)
                items.append(item)
            if touched:
                changed.add(person, day, _write(user, person, day, items, keep_appearance=False))
    return changed
```

```python
"""The Options panel's ticks (spec, section 2): defaults, the merge with
what the user saved, and the save that drops anything not an option."""

from shifts.models import GridOptions

DEFAULTS = {
    "staff_colours": True, "job_titles": False, "department_colours": True, "float_headers": True,
    "my_shifts_on_top": False, "only_my_shifts": False, "hide_no_shifts": False,
    "font_size": "md", "spacing": "normal", "days": [0, 1, 2, 3, 4, 5, 6], "paste": "replace",
}
CHOICES = {"font_size": ("sm", "md", "lg"), "spacing": ("tight", "normal", "loose"), "paste": ("replace", "add")}


def for_user(user):
    saved = GridOptions.objects.filter(user=user).values_list("data", flat=True).first() or {}
    return {**DEFAULTS, **{k: v for k, v in saved.items() if k in DEFAULTS}}


def clean(data):
    out = {}
    for key, default in DEFAULTS.items():
        if key not in data:
            continue
        value = data[key]
        if key in CHOICES:
            out[key] = value if value in CHOICES[key] else default
        elif key == "days":
            out[key] = sorted({int(d) for d in value if str(d).isdigit() and 0 <= int(d) <= 6}) or default
        else:
            out[key] = bool(value)
    return out


def save(user, data):
    row, _ = GridOptions.objects.get_or_create(user=user)
    row.data = {**row.data, **clean(data)}
    row.save(update_fields=["data"])
    return for_user(user)
```

```python
"""Common and Recent shift shapes for the right-click menu (spec, section
5): not stored, computed from recent entries."""

from datetime import timedelta

from django.db.models import Count
from django.utils import timezone

from people.models import Department
from people.services import access
from shifts.models import Entry
from shifts.services import serialize

WINDOW = timedelta(weeks=12)
LIMIT = 10


def _label(start, finish, break_minutes, dept):
    parts = [f"{serialize.time(start)}–{serialize.time(finish)}"]
    if break_minutes == 60:
        parts.append("1 hour break")
    elif break_minutes:
        parts.append(f"{break_minutes} min break")
    if dept is not None:
        parts.append(dept.name)
    return " ".join(parts)


def _shapes(rows):
    depts = {d.pk: d for d in Department.objects.all()}
    out = []
    for r in rows:
        dept = depts.get(r["department_id"])
        out.append({"start": serialize.time(r["start"]), "finish": serialize.time(r["finish"]),
                    "break_minutes": r["break_minutes"], "department": r["department_id"],
                    "label": _label(r["start"], r["finish"], r["break_minutes"], dept)})
    return out


def common(user):
    since = timezone.localdate() - WINDOW
    rows = (Entry.objects.filter(kind=Entry.Kind.SHIFT, day__gte=since, person__in=access.managed_people(user))
            .values("start", "finish", "break_minutes", "department_id")
            .annotate(n=Count("id")).order_by("-n", "start")[:LIMIT])
    return _shapes(rows)


def recent(user):
    seen, rows = set(), []
    for r in (Entry.objects.filter(kind=Entry.Kind.SHIFT, created_by=user).order_by("-created_at")
              .values("start", "finish", "break_minutes", "department_id")[:200]):
        key = (r["start"], r["finish"], r["break_minutes"], r["department_id"])
        if key in seen:
            continue
        seen.add(key)
        rows.append(r)
        if len(rows) == LIMIT:
            break
    return _shapes(rows)
```

```python
"""One payload for the grid's window (spec, sections 3 and 6): who is a
row for this viewer, what is in each cell, and the viewer's options."""

from datetime import timedelta

from django.db.models import Q
from django.utils import timezone

from people.models import Department, Person
from people.services import access
from shifts.models import DayChange, Entry, GpSession
from shifts.services import common, options, serialize

MAX_WEEKS = 20
DAY_LABEL = "%a. %b. {d}"


def monday(day):
    return day - timedelta(days=day.weekday())


def clamp_weeks(value):
    try:
        return min(max(int(value), 1), MAX_WEEKS)
    except (TypeError, ValueError):
        return 1


def visible_people(user, first, last):
    """People current on at least one day of the window with display_on_rota
    (section 6); for staff, also shown to other staff; a viewer who may not
    see others sees themselves only. The viewer is always their own row."""
    me = getattr(user, "person", None)
    people = Person.objects.filter(display_on_rota=True, start_date__lte=last).filter(
        Q(end_date__isnull=True) | Q(end_date__gte=first)).select_related("team")
    if access.is_manager(user):
        return people
    if me is None:
        return people.filter(show_to_other_staff=True)
    if not me.can_see_other_staff:
        return Person.objects.filter(pk=me.pk).select_related("team")
    return (people.filter(show_to_other_staff=True) | Person.objects.filter(pk=me.pk)).distinct()


def _ids(values):
    return [int(v) for v in values if str(v).isdigit()]


def _filtered(people, filters, first, last):
    name = (filters.get("name") or "").strip()
    if name:
        people = people.filter(name__icontains=name)
    teams = _ids(filters.getlist("team") if hasattr(filters, "getlist") else filters.get("team", []))
    if teams:
        people = people.filter(team_id__in=teams)
    depts = _ids(filters.getlist("dept") if hasattr(filters, "getlist") else filters.get("dept", []))
    if depts:
        tagged = Entry.objects.filter(day__range=(first, last), department_id__in=depts).values("person_id")
        people = people.filter(pk__in=tagged)
    return people


def payload(user, start, weeks, filters):
    first = monday(start)
    last = first + timedelta(days=7 * weeks - 1)
    today = timezone.localdate()
    days = [first + timedelta(days=i) for i in range(7 * weeks)]
    opts = options.for_user(user)
    me = getattr(user, "person", None)
    people = _filtered(visible_people(user, first, last), filters, first, last)
    if opts["only_my_shifts"] and me is not None:
        people = people.filter(pk=me.pk)
    people = list(people.order_by("team__display_order", "team__name", "display_order", "last_name", "first_name"))
    if opts["my_shifts_on_top"] and me is not None:
        people.sort(key=lambda p: p.pk != me.pk)

    by_cell = {}
    for e in Entry.objects.filter(person__in=people, day__range=(first, last)).select_related("department"):
        by_cell.setdefault(e.person_id, {}).setdefault(e.day.isoformat(), []).append(e)
    sessions = {}
    for s in GpSession.objects.filter(person__in=people, day__range=(first, last)):
        sessions.setdefault(s.person_id, {}).setdefault(s.day.isoformat(), []).append(
            {"part": s.part, "label": s.label, "site": s.site, "note": s.note})
    if opts["hide_no_shifts"]:
        people = [p for p in people if p.pk in by_cell or p.pk in sessions]

    rows = []
    for p in people:
        rows.append({
            "person": p.pk, "name": p.name, "colour": p.name_colour, "job_title": p.job_title,
            "team": p.team.name if p.team else "", "is_gp": p.is_gp,
            "editable": access.can_manage(user, p),
            "cells": {day: [serialize.entry(e) for e in sorted(es, key=lambda e: e.position)]
                      for day, es in by_cell.get(p.pk, {}).items()},
            "sessions": sessions.get(p.pk, {}),
        })
    manager = access.is_manager(user)
    return {
        "from": first.isoformat(), "weeks": weeks,
        "days": [{"date": d.isoformat(), "label": d.strftime(DAY_LABEL).format(d=d.day),
                  "today": d == today, "weekend": d.weekday() >= 5} for d in days],
        "rows": rows,
        "departments": [{"id": d.pk, "name": d.name, "colour": d.colour}
                        for d in Department.objects.filter(archived=False)],
        "common": common.common(user) if manager else [],
        "recent": common.recent(user) if manager else [],
        "options": opts,
        "unnotified": (DayChange.objects.filter(person__in=access.managed_people(user))
                       .values("person").distinct().count()) if manager else 0,
        "can_edit": any(r["editable"] for r in rows),
    }
```

```python
"""The grid's JSON API (spec, section 4). JSON in and out, never a redirect:
signed out is 401, refused is 403, bad input is 400, each with an "error"
sentence the island shows in its bar. Every write is a service call."""

import json
from datetime import date
from functools import wraps

from django.core.exceptions import PermissionDenied
from django.http import JsonResponse
from django.shortcuts import get_object_or_404
from django.views.decorators.http import require_GET, require_POST

from people.models import Person
from people.services import access, profiles

def api_login_required(view):
    @wraps(view)
    def wrapped(request, *args, **kwargs):
        if not request.user.is_authenticated:
            return JsonResponse({"error": "signed out"}, status=401)
        return view(request, *args, **kwargs)
    return wrapped


def json_view(view):
    """Parse the body into request.json and turn the services' refusals into
    status codes. A JSON body that is not an object is a 400 too."""
    @wraps(view)
    def wrapped(request, *args, **kwargs):
        if request.method == "POST":
            try:
                request.json = json.loads(request.body or b"{}")
            except ValueError:
                return JsonResponse({"error": "the request body is not JSON"}, status=400)
            if not isinstance(request.json, dict):
                return JsonResponse({"error": "the request body is not an object"}, status=400)
        try:
            return view(request, *args, **kwargs)
        except PermissionDenied as e:
            return JsonResponse({"error": str(e) or "you can't do that"}, status=403)
        except (ValueError, TypeError, KeyError) as e:
            return JsonResponse({"error": str(e) or "bad request"}, status=400)
    return wrapped


def _day(value):
    try:
        return date.fromisoformat(str(value))
    except ValueError:
        raise ValueError("that is not a date") from None


def _person(request):
    pk = request.json.get("person")
    if not str(pk).isdigit():
        raise ValueError("no person")
    return get_object_or_404(Person, pk=int(pk))


def _changed(request, result):
    body = serialize.changed(result)
    body["unnotified"] = window.payload_unnotified(request.user)
    return JsonResponse(body)

@require_GET
@json_view

    return JsonResponse(window.payload(request.user, start, weeks, request.GET))

    return _changed(request, _single(person, day, rows))

    result.add(person, day, rows)

    rows = list(Entry.objects.filter(person=entry.person, day=entry.day).select_related("department").order_by("position"))
    return _changed(request, _single(entry.person, entry.day, rows))

                                          bool(j.get("copy")), [int(p) for p in j.get("row_order", [])]))

                                           j.get("mode", "replace"), [int(p) for p in j.get("row_order", [])]))


@api_login_required
@require_POST
@json_view
def clear(request):
    return _changed(request, entries.clear(request.user, _cells(request)))


@api_login_required
@require_POST
@json_view

    j = request.json
    return _changed(request, entries.replace(request.user, _cells(request), str(j.get("find") or ""),
                                             str(j.get("replace") or ""), bool(j.get("match_case"))))
```

```python
"""Saved blocks (spec, section 5). Audited on shifts.template; the block
itself is not put in the log (it can be large), only the name."""

from django.db import IntegrityError, transaction

from people.services import audit
from shifts.models import Template


def save(user, name, block):
    if not isinstance(block, dict) or not isinstance(block.get("rows"), list):
        raise ValueError("the block has no rows")
    try:
        with transaction.atomic():
            t = Template.objects.create(name=name.strip(), created_by=user, block=block)
    except IntegrityError:
        raise ValueError("A template with this name already exists.") from None
    audit.record(user, t, {"name": ("", t.name)}, note="template saved")
    return t


def rename(user, template, name):
    before = template.name
    template.name = name.strip()
    try:
        with transaction.atomic():
            template.save(update_fields=["name"])
    except IntegrityError:
        raise ValueError("A template with this name already exists.") from None
    audit.record(user, template, {"name": (before, template.name)}, note="template renamed")
    return template


def delete(user, template):
    audit.record(user, template, {"name": (template.name, "")}, note="template deleted")
    template.delete()
```

```python
from django.contrib.auth.decorators import login_required
from django.http import HttpResponse
from django.shortcuts import render
from django.utils import timezone

from people.services import access
from shifts.services import window
from shifts.services import render as render_service


def _start(request):
    try:
        return window.monday(date.fromisoformat(request.GET.get("from", "")))
    except ValueError:
        return window.monday(timezone.localdate())


def _query(request, first, weeks):
    q = request.GET.copy()
    q["from"], q["weeks"] = first.isoformat(), str(weeks)
    return q.urlencode()


@login_required
def grid(request):
    first = _start(request)
    weeks = window.clamp_weeks(request.GET.get("weeks", 1))
    data = window.payload(request.user, first, 1, request.GET)   # the phone list's week; the island fetches its own
    me = getattr(request.user, "person", None)
    mine = [r for r in data["rows"] if me is not None and r["person"] == me.pk]
    return render(request, "shifts/grid.html", {
        "page_title": "Rota", "first": first, "weeks": weeks, "weeks_range": range(1, window.MAX_WEEKS + 1),
        "query": _query(request, first, weeks),
        "prev": _query(request, first - timedelta(weeks=weeks), weeks),
        "next": _query(request, first + timedelta(weeks=weeks), weeks),
        "today": _query(request, window.monday(timezone.localdate()), weeks),
        "filters": {k: request.GET.getlist(k) for k in ("name", "team", "dept")},
        "reorder": request.GET.get("reorder") == "1" and access.is_manager(request.user),
        "unnotified": data["unnotified"], "days": data["days"],
        "mine": mine, "others": [r for r in data["rows"] if r not in mine],
        "me_pk": me.pk if me else "",
    })


@login_required
def download(request):
    first = _start(request)
    weeks = window.clamp_weeks(request.GET.get("weeks", 1))
    data = window.payload(request.user, first, weeks, request.GET)
    response = HttpResponse(content_type="text/csv")
    response["Content-Disposition"] = f'attachment; filename="rota-{first.isoformat()}.csv"'
    writer = csv.writer(response)
    days = data["days"]
    writer.writerow(["Name", "Team"] + [date.fromisoformat(d["date"]).strftime("%a %-d %b") for d in days])
    for row in data["rows"]:
        cells = []
        for d in days:
            items = [e["line"] for e in row["cells"].get(d["date"], [])]
            items = [f"{s['part']} {s['label']} {s['site']}".strip() for s in row["sessions"].get(d["date"], [])] + items
            cells.append(" / ".join(items))
        writer.writerow([row["name"], row["team"]] + cells)
    return response
```

```python
REFRESH = {"refresh": True}


def _cells(text):
    """'12:2027-03-01,12:2027-03-02' → [(12, date), …]."""
    out = []
    for part in (text or "").split(","):
        if ":" not in part:
            continue
        pk, day = part.split(":", 1)
        if pk.isdigit():
            out.append((int(pk), date.fromisoformat(day)))
    if not out:
        raise ValueError("no cells selected")
    return out


def _row_order(text):
    return [int(p) for p in (text or "").split(",") if p.isdigit()]


@login_required
def shift(request, person_pk, day, entry_pk=None):
    person = get_object_or_404(Person, pk=person_pk)
    if not access.can_manage(request.user, person):
        raise PermissionDenied
    day = date.fromisoformat(day)
    entry = get_object_or_404(Entry, pk=entry_pk, person=person, day=day) if entry_pk else None
    if request.method == "POST":
        form = ShiftForm(request.POST)
        if form.is_valid():
            items = [{"kind": e.kind, "start": e.start and e.start.strftime("%H:%M"),
                      "finish": e.finish and e.finish.strftime("%H:%M"), "break_minutes": e.break_minutes,
                      "department": e.department_id, "text": e.text, "wfh": e.wfh, "overtime": e.overtime,
                      "appearance": e.appearance}
                     for e in Entry.objects.filter(person=person, day=day).order_by("position")]
            new = form.item()
            if entry is None:
                items.append(new)
            else:
                new["appearance"] = entry.appearance
                items[entry.position] = new
            try:
                entries.set_cell(request.user, person, day, items)
                return JsonResponse(REFRESH)
            except ValueError as e:
                form.add_error(None, str(e))
    else:
```

```ts
/** The grid's JSON calls. Never follows a redirect into HTML: a 401 is
 *  "signed out", any other non-2xx carries an "error" sentence, and a
 *  network failure is its own message. */
import type { Changed, WindowJson } from "./types";

export class ApiError extends Error {
  constructor(public status: number, message: string) { super(message); }
  get signedOut() { return this.status === 401; }
}

const UNREACHABLE = "The server couldn't be reached. Check your connection and try again.";

function csrf(): string {
  return (document.querySelector('meta[name="csrf-token"]') as HTMLMetaElement | null)?.content ?? "";
}

async function answer<T>(p: Promise<Response>): Promise<T> {
  let r: Response;
  try { r = await p; } catch { throw new ApiError(0, UNREACHABLE); }
  if (r.status === 401) throw new ApiError(401, "Your session ended.");
  let body: unknown = null;
  try { body = await r.json(); } catch { /* not JSON */ }
  if (!r.ok) {
    const message = (body as { error?: string } | null)?.error || `That didn't work (HTTP ${r.status}).`;
    throw new ApiError(r.status, message);
  }
  return body as T;
}

export function getWindow(api: string, from: string, weeks: number, filters: string): Promise<WindowJson> {
  const q = new URLSearchParams(filters);
  q.set("from", from); q.set("weeks", String(weeks));
  return answer(fetch(`${api}window/?${q}`, { headers: { "X-Requested-With": "fetch" }, credentials: "same-origin" }));
}

export function post<T = Changed>(api: string, path: string, body: unknown): Promise<T> {
  return answer(fetch(`${api}${path}`, {
    method: "POST", credentials: "same-origin", body: JSON.stringify(body),
    headers: { "Content-Type": "application/json", "X-CSRFToken": csrf(), "X-Requested-With": "fetch" },
  }));
}
```

```ts
import type { Department, Item, Overtime } from "./types";

const SIDE = (p: string) => `(?<${p}h>\\d{1,2})(?:[:.]?(?<${p}m>\\d{2}))?\\s*(?<${p}ap>am|pm)?`;
const RANGE = new RegExp(`(?<![\\d:.])${SIDE("a")}\\s*(?:-|–|—|to|until)\\s*${SIDE("b")}(?![\\d:.])`, "i");
const SEPARATOR = /^\s*-{3,}\s*$/;
const BREAK = /(?<!\w)(?:(?<h>\d+)\s*(?:hours?|hrs?|h)(?:\s+break)?|(?<m>\d+)\s*(?:minutes?|mins?|m)(?:\s+break)?|break\s+(?<n>\d+))(?!\w)/gi;
const WFH = /(?<!\w)wfh(?!\w)/gi;
const TOIL = /(?<!\w)toil(?!\w)/i;
const PAID = /(?<!\w)(?:ot paid|overtime paid|paid overtime|ot)(?!\w)/i;
const BREAKS = [0, 15, 30, 45, 60];

function hm(h: string, m: string | undefined, ap: string | undefined): [number, number] | null {
  let hour = parseInt(h, 10);
  const minute = m ? parseInt(m, 10) : 0;
  if (hour > 23 || minute > 59) return null;
  const marker = (ap || "").toLowerCase();
  if (marker === "pm" && hour < 12) hour += 12;
  if (marker === "am" && hour === 12) hour = 0;
  if (marker && hour > 23) return null;
  return [hour, minute];
}

const pad = (n: number) => String(n).padStart(2, "0");
const fmt = (t: [number, number]) => `${pad(t[0])}:${pad(t[1])}`;
const minutes = (t: [number, number]) => t[0] * 60 + t[1];

function range(m: RegExpMatchArray): [string, string] | null {
  const g = m.groups!;
  const start = hm(g.ah, g.am, g.aap);
  let finish = hm(g.bh, g.bm, g.bap);
  if (!start || !finish) return null;
  if (!g.bap && minutes(finish) <= minutes(start) && finish[0] < 12) finish = [finish[0] + 12, finish[1]];
  if (minutes(finish) <= minutes(start)) return null;
  return [fmt(start), fmt(finish)];
}

function takeBreak(rest: string): [number, string] {
  for (const m of rest.matchAll(BREAK)) {
    const g = m.groups!;
    const mins = g.h ? parseInt(g.h, 10) * 60 : parseInt(g.m || g.n, 10);
    if (BREAKS.includes(mins)) return [mins, rest.slice(0, m.index) + " " + rest.slice(m.index! + m[0].length)];
  }
  return [0, rest];
}

const escape = (s: string) => s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");

function takeDepartment(rest: string, departments: Department[]): [number | null, string] {
  for (const d of [...departments].sort((a, b) => b.name.length - a.name.length)) {
    const m = new RegExp(`(?<!\\w)${escape(d.name)}(?!\\w)`, "i").exec(rest);
    if (m) return [d.id, rest.slice(0, m.index) + " " + rest.slice(m.index + m[0].length)];
  }
  return [null, rest];
}

const comment = (text: string) => text.split(/\s+/).filter(Boolean).join(" ").slice(0, 200);

export function parseLine(text: string, departments: Department[]): Item {
  if (SEPARATOR.test(text)) return { kind: "separator" };
  const m = RANGE.exec(text);
  const times = m ? range(m) : null;
  if (!m || !times) return { kind: "comment", text: comment(text) };
  let rest = text.slice(0, m.index) + " " + text.slice(m.index + m[0].length);
  let break_minutes: number;
  [break_minutes, rest] = takeBreak(rest);
  const wfh = WFH.test(rest); WFH.lastIndex = 0;
  rest = rest.replace(WFH, " ");
  let overtime: Overtime = "";
  if (TOIL.test(rest)) { overtime = "toil"; rest = rest.replace(TOIL, " "); }
  else if (PAID.test(rest)) { overtime = "paid"; rest = rest.replace(PAID, " "); }
  let department: number | null;
  [department, rest] = takeDepartment(rest, departments);
  return { kind: "shift", start: times[0], finish: times[1], break_minutes, department, text: comment(rest), wfh, overtime };
}

export function parseCell(text: string, departments: Department[]): Item[] {
  return text.split(/\r?\n/).filter((l) => l.trim()).map((l) => parseLine(l, departments));
}

/** The canonical line, as shifts/services/render.py writes it. */
export function renderLine(item: Item, departments: Department[]): string {
  if (item.kind === "separator") return "---";
  if (item.kind === "comment") return item.text || "";
  const parts = [`${item.start}-${item.finish}`];
  if (item.break_minutes === 60) parts.push("1 hour break");
  else if (item.break_minutes) parts.push(`${item.break_minutes} min break`);
  const dept = departments.find((d) => d.id === item.department);
  if (dept) parts.push(dept.name);
  if (item.wfh) parts.push("WFH");
  if (item.overtime) parts.push(item.overtime === "paid" ? "OT paid" : "TOIL");
  if (item.text) parts.push(item.text);
  return parts.join(" ");
}
```

```ts
/** A selection is a Set of "person:date" keys; blocks are rectangles over
 *  the grid's row order and day list. */
export type CellKey = string;

export const key = (person: number, date: string): CellKey => `${person}:${date}`;
export function split(k: CellKey): [number, string] {
  const i = k.indexOf(":");
  return [parseInt(k.slice(0, i), 10), k.slice(i + 1)];
}

export function block(people: number[], days: string[], a: CellKey, b: CellKey): Set<CellKey> {
  const [pa, da] = split(a), [pb, db] = split(b);
  const r0 = Math.min(people.indexOf(pa), people.indexOf(pb)), r1 = Math.max(people.indexOf(pa), people.indexOf(pb));
  const d0 = Math.min(days.indexOf(da), days.indexOf(db)), d1 = Math.max(days.indexOf(da), days.indexOf(db));
  const out = new Set<CellKey>();
  if (r0 < 0 || d0 < 0) return out;
  for (let r = r0; r <= r1; r++) for (let d = d0; d <= d1; d++) out.add(key(people[r], days[d]));
  return out;
}

export function bounds(sel: Set<CellKey>, people: number[], days: string[]) {
  let r0 = Infinity, r1 = -1, d0 = Infinity, d1 = -1;
  for (const k of sel) {
    const [p, d] = split(k);
    const r = people.indexOf(p), c = days.indexOf(d);
    if (r < 0 || c < 0) continue;
    r0 = Math.min(r0, r); r1 = Math.max(r1, r); d0 = Math.min(d0, c); d1 = Math.max(d1, c);
  }
  return r1 < 0 ? null : { r0, r1, d0, d1 };
}
```

```ts
/** Blocks (spec, section 5): the selection's bounding rectangle as rows of
 *  day offsets, kept in the island and in localStorage, and written to the
 *  system clipboard as tab-separated text for Excel. */
import { parseCell, renderLine } from "./parser";
import { bounds, key, type CellKey } from "./selection";
import { toItem, type Block, type Department, type EntryJson } from "./types";

const STORE = "shift-central.clipboard";

export function toBlock(sel: Set<CellKey>, people: number[], days: string[], entries: (k: CellKey) => EntryJson[]) {
  const b = bounds(sel, people, days);
  if (!b) return null;
  const rows = [];
  for (let r = b.r0; r <= b.r1; r++) {
    const row = [];
    for (let d = b.d0; d <= b.d1; d++) {
      const k = key(people[r], days[d]);
      row.push(sel.has(k) ? entries(k).map(toItem) : []);
    }
    rows.push(row);
  }
  return { block: { days: b.d1 - b.d0 + 1, rows } as Block, anchor: [people[b.r0], days[b.d0]] as [number, string] };
}

export function toTSV(block: Block, departments: Department[]): string {
  return block.rows.map((row) => row.map((items) => items.map((i) => renderLine(i, departments)).join(" / ")).join("\t")).join("\n");
}

/** Text from outside the island: tabs are days, lines are rows, " / "
 *  separates items within a cell. */
export function fromText(text: string, departments: Department[]): Block {
  const rows = text.replace(/\r/g, "").split("\n").filter((l) => l.length).map((line) =>
    line.split("\t").map((cell) => parseCell(cell.split(" / ").join("\n"), departments)));
  const days = Math.max(1, ...rows.map((r) => r.length));
  return { days, rows: rows.map((r) => { while (r.length < days) r.push([]); return r; }) };
}

export function save(block: Block, tsv: string) {
  try { localStorage.setItem(STORE, JSON.stringify({ block, tsv })); } catch { /* private window */ }
  try { navigator.clipboard?.writeText(tsv); } catch { /* no permission */ }
}

export function load(): { block: Block; tsv: string } | null {
  try { const raw = localStorage.getItem(STORE); return raw ? JSON.parse(raw) : null; } catch { return null; }
}
```

```tsx
/** The right-click menu (spec, section 3): a navy panel with submenus,
 *  closed by Escape, a click away or an action. Items that open a window
 *  are plain data-dialog anchors, so modal.js handles them. */
import { useEffect, useRef, useState } from "preact/hooks";
import type { Department, Shape } from "./types";

export interface MenuItem { label: string; action?: () => void; href?: string; children?: MenuItem[]; disabled?: boolean; swatch?: string; note?: string }
export interface MenuProps { x: number; y: number; items: MenuItem[]; onClose: () => void }

export function Menu({ x, y, items, onClose }: MenuProps) {
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => {
    const away = (e: MouseEvent) => { if (!ref.current?.contains(e.target as Node)) onClose(); };
    const esc = (e: KeyboardEvent) => { if (e.key === "Escape") { e.stopPropagation(); onClose(); } };
    document.addEventListener("mousedown", away);
    document.addEventListener("keydown", esc, true);
    return () => { document.removeEventListener("mousedown", away); document.removeEventListener("keydown", esc, true); };
  }, [onClose]);
  // Keep the panel on screen.
  const left = Math.min(x, window.innerWidth - 240), top = Math.min(y, window.innerHeight - 20 - items.length * 28);
  return <div class="rota-menu" ref={ref} style={{ left, top }} role="menu"><List items={items} onClose={onClose} /></div>;
}

function List({ items, onClose }: { items: MenuItem[]; onClose: () => void }) {
  const [open, setOpen] = useState<number | null>(null);
  return (
    <ul>
      {items.map((it, i) => (
        <li key={i} class={[it.children && "has-sub", it.disabled && "is-disabled"].filter(Boolean).join(" ")}
            onMouseEnter={() => setOpen(it.children ? i : null)}>
          {it.href ? (
            <a href={it.href} data-dialog role="menuitem" onClick={() => setTimeout(onClose, 0)}>{it.label}</a>
          ) : (
            <button type="button" role="menuitem" disabled={it.disabled} aria-haspopup={it.children ? "menu" : undefined}
                    onClick={() => { if (it.children) { setOpen(i); return; } it.action?.(); onClose(); }}>

              {it.label}{it.note ? <span class="rota-menu-note">{it.note}</span> : null}
            </button>
          )}
          {it.children && open === i ? <div class="rota-menu-sub"><List items={it.children} onClose={onClose} /></div> : null}
        </li>
      ))}
    </ul>
  );
}
```

```python
"""Notify staff (ROTA-09, NOTIF-02): one plain-text summary per person of
every day changed since they were last told, from the DayChange rows. A
day whose text is back to what it was sends nothing. A failed send keeps
the rows for next time."""

from datetime import timedelta

from django.conf import settings
from django.core.exceptions import PermissionDenied
from django.db import transaction
from django.utils import timezone

from messaging.services import send as send_mail
from people.services import access, audit
from shifts.models import DayChange
from shifts.services import render
from shifts.services.window import monday

OLD = timedelta(days=7)
SUBJECT = "Your rota has changed"


def _day_label(day):
    return f"{day:%a} {day.day} {day:%b %Y}"


def lines(person):
    out = []
    for change in DayChange.objects.filter(person=person).order_by("day"):
        now = render.day_text(person, change.day)
        if now == change.before:
            continue
        out.append(f"{_day_label(change.day)}: {now} (was {change.before})")
    return out


def _first_changed(person):
    for change in DayChange.objects.filter(person=person).order_by("day"):
        if render.day_text(person, change.day) != change.before:
            return change.day
    return None


def pending(user):
    """Everyone the user manages with unnotified rows, each with a reason
    when nothing can be sent."""
    people = access.managed_people(user).filter(day_changes__isnull=False).distinct().order_by("name")
    out = []
    for person in people:
        days = list(DayChange.objects.filter(person=person).order_by("day").values_list("day", flat=True))
        reason = ""
        if not lines(person):
            reason = "changes cancel out"
        elif not person.email:
            reason = "no email"
        out.append({"person": person, "days": days, "reason": reason})
    return out


def _body(person, first):
    host = settings.CSRF_TRUSTED_ORIGINS[0] if settings.CSRF_TRUSTED_ORIGINS else ""
    link = f"{host}/rota/?from={monday(first).isoformat()}"
    return "\n".join(["Your rota has changed. Here is what is different:", "", *lines(person), "",
                      f"See your rota: {link}", ""])


def send(user, person_ids):
    allowed = {p.pk: p for p in access.managed_people(user).filter(pk__in=person_ids)}
    if set(person_ids) - set(allowed):
        raise PermissionDenied("not your team")
    out = {"sent": [], "failed": [], "skipped": []}
    for pk in person_ids:
        person = allowed[pk]
        first = _first_changed(person)
        if first is None:
            DayChange.objects.filter(person=person).delete()
            out["skipped"].append(person)
            continue
        if not person.email:
            out["skipped"].append(person)
            continue
        count = len(lines(person))
        row = send_mail(person, SUBJECT, _body(person, first))
        if row.sent_at is None:
            out["failed"].append(person)
            continue
        with transaction.atomic():
            DayChange.objects.filter(person=person).delete()
            audit.record_as(user, "shifts.entry", person.pk, {"notified": ("", str(count))},
                            note=f"rota changes sent · {person.name}")
        out["sent"].append(person)
    return out


def old_count(user):
    return (DayChange.objects.filter(person__in=access.managed_people(user), at__lt=timezone.now() - OLD)
            .values("person").distinct().count())
```

```python
"""The read-only feed Shift Central polls (its spec, section 9).

GET /api/v1/sessions?from=YYYY-MM-DD&to=YYYY-MM-DD
    {"from": "…", "to": "…",
     "sessions": [{"email": "a.gp@…", "day": "2027-01-04", "part": "AM",
                   "type": "Surgery", "site": "AG", "note": ""}],
     "without_email": 1}
    Published entries whose clinician has a login with an email, from and
    to inclusive, at most 500 days. `without_email` counts the clinicians
    with published entries in the range but no email, so the other side can
    say someone is missing. Nothing here is written to.
"""

from datetime import date

from django.http import JsonResponse

from api.auth import token_required
from rota.models import RotaEntry

MAX_DAYS = 500


def _bad(message):
    return JsonResponse({"error": message}, status=400)


@token_required
def sessions(request):
    try:
        start = date.fromisoformat(request.GET.get("from", ""))
        end = date.fromisoformat(request.GET.get("to", ""))
    except ValueError:
        return _bad("from and to must be dates (YYYY-MM-DD)")
    if end < start:
        return _bad("to is before from")
    if (end - start).days > MAX_DAYS:
        return _bad(f"the range is over {MAX_DAYS} days")
    rows = (RotaEntry.objects.filter(is_published=True, day__range=(start, end))
            .select_related("clinician__user", "session_type", "site").order_by("day", "part", "clinician__name"))
    out, without_email = [], set()
    for e in rows:
        user = e.clinician.user
        if user is None or not user.email:
            without_email.add(e.clinician_id)
            continue
        out.append({"email": user.email, "day": e.day.isoformat(), "part": e.part, "type": e.session_type.name,
                    "site": e.site.name if e.site else "", "note": e.note})
    return JsonResponse({"from": start.isoformat(), "to": end.isoformat(), "sessions": out,
                         "without_email": len(without_email)})
```

```python
"""A read-only client for the GP rota app's sessions feed, on the standard
library, in hr_client's pattern: https only outside DEBUG, no redirects,
the token never logged, the body never logged."""

import json
import logging
import urllib.error
import urllib.request
from urllib.parse import urlencode, urlparse

from django.conf import settings

log = logging.getLogger("shifts.gp_sync")


class _RefuseRedirects(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None


_OPENER = urllib.request.build_opener(_RefuseRedirects)


class GpError(Exception):
    pass


class GpClient:
    def __init__(self, base_url, token, *, opener=None, timeout=10):
        self.base_url = base_url.rstrip("/")
        self._token = token
        self._open = opener or (lambda req: _OPENER.open(req, timeout=timeout))

    def sessions(self, start, end):
        url = f"{self.base_url}/api/v1/sessions?" + urlencode({"from": start.isoformat(), "to": end.isoformat()})
        if urlparse(url).scheme != "https" and not settings.DEBUG:
            raise GpError("ROTA_URL is not https; the token was not sent")
        req = urllib.request.Request(url, method="GET", headers={
            "Accept": "application/json", "Authorization": f"Bearer {self._token}"})
        try:
            with self._open(req) as resp:
                raw = resp.read()
        except urllib.error.HTTPError as e:
            log.warning("gp sessions -> %s", e.code)
            raise GpError(f"GP rota returned {e.code} for sessions") from None
        except (urllib.error.URLError, OSError) as e:
            log.warning("gp sessions unreachable: %s", e.__class__.__name__)
            raise GpError("GP rota unreachable") from None
        try:
            body = json.loads(raw)
        except ValueError:
            raise GpError("GP rota returned a non-JSON body for sessions") from None
        if not isinstance(body, dict) or not isinstance(body.get("sessions"), list):
            raise GpError("GP rota's sessions response has no 'sessions' list")
        return body

    @classmethod
    def from_settings(cls):
        return cls(settings.ROTA_URL, settings.ROTA_API_TOKEN)
```

`shifts/services/gp_sync.py`:

```python
"""GP sessions from the rota app (spec, section 9): one window fetched,
matched to GPs by email, the window's rows replaced in one transaction.
Never raises; a failure is the run's message and the previous rows stand.
Emails are record values: they go in the run's `detail` for the Health
card, never in `message` or a log line."""

import logging
from datetime import date, timedelta

from django.conf import settings
from django.db import transaction
from django.utils import timezone

from people.models import Person, SyncRun
from shifts.models import GpSession
from shifts.services.gp_client import GpClient, GpError

log = logging.getLogger("shifts.gp_sync")
SOURCE = "gp-rota"
BACK = timedelta(weeks=8)
AHEAD = timedelta(weeks=52)


class BadRecord(Exception):
    pass


def configured():
    return bool(settings.ROTA_URL and settings.ROTA_API_TOKEN)


def _parse(record, position):
    try:
        email = str(record["email"]).strip().lower()
        day = date.fromisoformat(record["day"])
        part = str(record["part"])
        if part not in ("AM", "PM"):
            raise ValueError
        return email, {"day": day, "part": part, "label": str(record.get("type") or "")[:60],
                       "site": str(record.get("site") or "")[:60], "note": str(record.get("note") or "")[:200]}
    except (KeyError, TypeError, ValueError, AttributeError):
        raise BadRecord(f"session {position} in the feed: missing or bad email, day or part") from None


def _apply(payload, start, end, now):
    gps = {p.email.lower(): p for p in Person.objects.filter(is_gp=True).exclude(email="")}
    rows, unmatched, matched = [], set(), set()
    for position, record in enumerate(payload["sessions"], start=1):
        email, fields = _parse(record, position)
        person = gps.get(email)
        if person is None:
            unmatched.add(email)
            continue
        matched.add(person.pk)
        rows.append(GpSession(person=person, synced_at=now, **fields))
    with transaction.atomic():
        GpSession.objects.filter(day__range=(start, end)).delete()
        GpSession.objects.bulk_create(rows)
    return len(matched), sorted(unmatched), int(payload.get("without_email") or 0)


def sync(client=None, now=None):
    client = client or GpClient.from_settings()
    now = now or timezone.now()
    today = timezone.localtime(now).date()
    start, end = today - BACK, today + AHEAD
    run = SyncRun.objects.create(source=SOURCE)
    try:
        payload = client.sessions(start, end)
        seen, unmatched, without_email = _apply(payload, start, end, now)
        run.ok, run.people_seen = True, seen
        run.detail = {"unmatched": unmatched, "without_email": without_email}
        notes = []
        if unmatched:
            notes.append(f"{len(unmatched)} email{'s' if len(unmatched) != 1 else ''} unmatched")
        if without_email:
            notes.append(f"{without_email} clinician{'s' if without_email != 1 else ''} without an email")
        run.message = "; ".join(notes)
    except (GpError, BadRecord) as e:
        run.message = str(e)[:300]
        log.warning("gp_sync failed: %s", run.message)
    except Exception:
        run.message = "unexpected error; see the journal"
        log.exception("gp_sync failed")
    finally:
        run.finished_at = timezone.now()
        run.save()
    return run


def last_run():
    return SyncRun.objects.filter(source=SOURCE).first()


def unmatched():
    run = SyncRun.objects.filter(source=SOURCE, ok=True).first()
    return list(run.detail.get("unmatched", [])) if run else []
```

```python
            people = people | Person.objects.filter(pk=me.pk)
        return people.distinct().order_by("team__display_order", "team__name", "display_order", "last_name")
    return Person.objects.filter(pk=me.pk) if me is not None else Person.objects.none()


def _rows(person, start, end):
    rows = []
    for e in Entry.objects.filter(person=person, day__range=(start, end), kind=Entry.Kind.SHIFT).order_by("day", "position"):
        worked = e.hours
        rows.append({"day": e.day, "start": e.start, "finish": e.finish, "break_minutes": e.break_minutes,
                     "hours": timedelta(0) if e.overtime else worked, "overtime": worked if e.overtime else timedelta(0),
                     "label": e.department.name if e.department else e.text})
    for s in GpSession.objects.filter(person=person, day__range=(start, end)).order_by("day", "part"):
        rows.append({"day": s.day, "start": None, "finish": None, "break_minutes": 0, "hours": GpSession.HOURS,
                     "overtime": timedelta(0), "label": " ".join(x for x in (s.part, s.label, s.site) if x)})
    rows.sort(key=lambda r: (r["day"], r["start"] or time(0)))
    return rows


def report(user, start, end):
    if end < start:
        start, end = end, start
    if end - start > MAX_RANGE:
        start = end - MAX_RANGE
    blocks = []
    for person in people_for(user):
        rows = _rows(person, start, end)
        weeks = []
        for r in rows:
            week_start = monday(r["day"])
            if not weeks or weeks[-1]["start"] != week_start:
                weeks.append({"start": week_start, "rows": [], "subtotal": timedelta(0), "overtime": timedelta(0)})
            weeks[-1]["rows"].append(r)
            weeks[-1]["subtotal"] += r["hours"]
            weeks[-1]["overtime"] += r["overtime"]
        blocks.append({"person": person, "shifts": len(rows), "weeks": weeks,
                       "total": sum((r["hours"] for r in rows), timedelta(0)),
                       "overtime": sum((r["overtime"] for r in rows), timedelta(0))})
    return blocks
```

```python
"""Who's in today (ROTA-12): everyone across all teams by site, WFH
listed apart, and "off" meaning no shift and no session until spec 3
brings time off."""

import re
from collections import OrderedDict

from people.models import Person
from shifts.models import Entry, GpSession
from shifts.services import render

SITES = ("AG", "PMC", "Either")


def site_of(entry):
    name = entry.department.name if entry.department else ""
    for site in ("AG", "PMC"):
        if re.search(r"(?<!\w)" + site + r"(?!\w)", name):
            return site
    return "Either"


def board(day):
    people = list(Person.objects.current(on=day).filter(display_on_rota=True).select_related("team"))
    by_site = {s: OrderedDict() for s in SITES}
    wfh, working = [], set()
    for e in Entry.objects.filter(person__in=people, day=day, kind=Entry.Kind.SHIFT).select_related("person__team", "department").order_by("person__team__display_order", "person__display_order", "person__last_name", "position"):
        working.add(e.person_id)
        if e.wfh:
            wfh.append((e.person, render.line(e)))
            continue
        team = by_site[site_of(e)].setdefault(e.person.team.name if e.person.team else "—", OrderedDict())
        team.setdefault(e.person, []).append(render.line(e))
    for s in GpSession.objects.filter(person__in=people, day=day).select_related("person__team").order_by("part"):
        working.add(s.person_id)
        site = s.site if s.site in ("AG", "PMC") else "Either"
        team = by_site[site].setdefault(s.person.team.name if s.person.team else "—", OrderedDict())
        team.setdefault(s.person, []).append(" ".join(x for x in (s.part, s.label, s.site) if x))
    grouped = OrderedDict()
    for person, line in wfh:
        grouped.setdefault(person, []).append(line)
    return {
        "sites": [{"name": site, "teams": [{"team": team, "people": [{"person": p, "lines": lines} for p, lines in members.items()]}
                                           for team, members in by_site[site].items()]}
                  for site in SITES if by_site[site]],
        "wfh": [{"person": p, "lines": lines} for p, lines in grouped.items()],
        "off": [p for p in people if p.pk not in working],
    }
```
