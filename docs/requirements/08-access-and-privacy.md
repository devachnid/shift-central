# 08 — Access and privacy

**ACC-01** — **Everyone logs in** (about 59 people: all staff, the cleaner and all GPs) with their **one Practice HR account**.
*Why:* one account across all the practice's apps.

**ACC-02** — Three roles:
- **Staff member** — everyone.
- **Team manager** — manager access for one team (lead nurse: nursing; head pharmacist: pharmacy).
- **All-teams manager** — manager access for every team (practice manager and 3 assistant managers).

**ACC-03** — **All staff can see all rotas, for every team.** Each person's "can see other staff" switch remains available so a manager can restrict someone if needed.

**ACC-04** — Profile **notes** are visible to **managers only**.

**ACC-05** — When someone is off, colleagues see the **leave type only** (e.g. Holiday, Training, Sick). The **overtyped description** and **paid/unpaid** are visible to the person themselves and to managers only.
*Why:* descriptions can be sensitive.

**ACC-06** — Who sees what:

| Information | The person | Other staff | Team manager (own team) | All-teams manager |
|---|---|---|---|---|
| All rotas, all teams | ✓ | ✓ | ✓ | ✓ |
| Leave type when someone is off | ✓ | ✓ | ✓ | ✓ |
| Overtyped description and paid/unpaid | Own | ✗ | ✓ | ✓ |
| Leave balances | Own | ✗ | ✓ | ✓ |
| Approved and pending time off | ✓ | ✓ | ✓ | ✓ |
| Instances of absence and trigger level | Own | ✗ | ✓ | ✓ |
| Profile contact details (email, mobile) | Own | ✗ | ✓ | ✓ |
| Profile notes | ✗ | ✗ | ✓ | ✓ |
| Log of manual balance changes | ✗ | ✗ | ✓ | ✓ |
| Hours report | Own | ✗ | ✓ | ✓ |
| Past schedule section (historical sickness) | ✗ | ✗ | ✓ | ✓ |
| Log-in logs | ✗ | ✗ | ✗ | ✓ |
| Pay rates and budget (future) | ✗ | ✗ | ✗ | ✓ |
| Edit rotas, approve leave, change allowances | ✗ | ✗ | ✓ | ✓ |

**ACC-07** — **Log-in logs**: every log-in is recorded with date and time. Visible to all-teams managers.

**ACC-08** — **Activity log**: who changed what on the rota and when (FMS item 65).

**ACC-09** — **Devices:** work PCs (some shared, e.g. reception) and personal phones. Logging out must be easy, and users are **logged out automatically after 10 minutes of inactivity**.

**ACC-10** — Sensitive data held: contact details, date of birth, gender, sickness dates, family leave, paid/unpaid status, and (future) pay rates. Whether sickness reasons should be recorded at all was not discussed — see open questions in `12`.

## Not needed, on purpose

- Logins for people outside the practice; guest accounts.
- Hiding other teams' rotas from staff.
- Showing sickness or other leave reasons to colleagues.
