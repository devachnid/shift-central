# 11 — Priorities

## First release, in the practice manager's words

"The system needs to be ready as soon as possible so that I can start to populate the data ahead of full launch on 01/01/2027." Everything listed as **Must** is to be **in place for launch in January**.

**Build order** (so data set-up can start as early as possible):
1. Staff profiles, departments and allowances (with sign-in through Practice HR)
2. The rota grid
3. Leave requests, approval and the leave calculations
4. Then, still before launch: payroll report, sickness and triggers (with the past schedule section), GP rota app sync, open shifts, reports and one-pagers, push notifications, year-end carry-over flag

## Failure — what would make this a failure

1. **The leave figures do not match the agreed formulas.** Test: every worked example in `06` gives exactly the expected answer.
2. **The app is not user friendly.** Test: staff use it without training and without asking managers how (MIG-07).
3. **It does not look and feel like FindMyShift.** Test: visuals and functionality very close to FindMyShift, screen by screen, as described in `03` (FMS-00), using the AMG Shift Central name and logo.

## Success — "it works" in six months (July 2027)

- **No more manual spreadsheets**: payroll, hours and leave figures all come from the system.
- **Every leave balance can be explained**, and no staff member has queried a wrong figure.
- **All staff use the app** to check shifts and request leave, without asking managers how.
- **Manual tasks are automated**, saving the practice time, effort and money.
