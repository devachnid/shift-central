## Requirements

**PEOPLE-01** — Every person above (about 59) has one account, appears on the rota and has their leave managed in the system.
*Why:* the practice wants everyone in one place; there are no outside workers to exclude.

**PEOPLE-02** — GP partners, salaried GPs and trainees are handled the same way as staff for leave (hours allowance, same rules).
*Why:* the practice manager confirmed no group of GPs is treated differently.

**PEOPLE-03** — A person belongs to one team, but any shift can carry any department tag. A receptionist doing a prescriptions day stays a receptionist with one contract, one leave balance and the same managers; only that day's shift is tagged differently (e.g. "Prescriptions", "VAS/Enhanced").
*Why:* split-role receptionists have one reception contract; the split only matters on the rota.

**PEOPLE-04** — Manager access is given per team. The current set-up must be possible:

| Team | Manager access |
|---|---|
| Reception, Admin/Secretarial, Management, Cleaning | Practice manager + 3 assistant managers |
| Nursing | Practice manager + 3 assistant managers + lead nurse |
| Pharmacy | Practice manager + 3 assistant managers + head pharmacist |
| GPs | Practice manager + 3 assistant managers |

*Why:* the practice manager and assistant managers cover every team; the clinical leads run their own teams day to day.

**PEOPLE-05** — Whoever has manager access for a team can build and change its rota **and** approve its leave. The approver is **not** taken from the line manager recorded in Practice HR.
*Why:* the practice decided approval follows manager access. **Differs from the Practice HR design**, where the line manager approves.

**PEOPLE-06** — Any of several managers with access to a team can approve; one approval is enough.
*Why:* access is shared, so cover when someone is away is automatic.

**PEOPLE-07** — Approval of managers' own leave:
- The lead nurse, head pharmacist and assistant managers have their leave approved by the practice manager (or another all-teams manager — managers can approve each other's requests, see `07`).
- Managers cannot approve their own leave.
- The **practice manager's own leave is recorded without approval.**
*Why:* as stated by the practice manager.

## Who builds which rota

**PEOPLE-08** — Each team's rota is built and changed by anyone with manager access for that team (PEOPLE-04). GP rotas are built in the same grid (see `02`).

## Not needed, on purpose

- PCN/ARRS, federation, agency, bank, casual or zero-hours staff — the practice has none.
- Care coordinators, social prescribers, physician associates, paramedics, mental-health practitioners — none at the practice.
- Locums — no regular locums.
- Separate contracts for split-role staff.
- Using Practice HR line managers to decide approvers.
- Delegating approval while a manager is away (shared access covers it).
